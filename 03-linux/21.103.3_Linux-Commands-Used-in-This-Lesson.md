# LPIC-103.3 — Linux Commands Used in This Lesson

| Komut | Anlamı |
|---|---|
| `*` / `?` / `[ ]` | Joker karakterler (file globbing — bash genişletir) |
| `ls` | Dizindeki dosya ve dizinleri listeler |
| `ls -1` | Her satırda bir dosya gösterir |
| `ls -l` | Uzun format (izin, sahip, boyut, tarih) |
| `ls -ltrh` | Zamana göre (ters), uzun ve okunabilir boyut |
| `cp` | Dosya kopyalar |
| `cp -r` | Dizini içeriğiyle özyinelemeli kopyalar |
| `cp -v` / `-i` / `-f` / `-p` / `-b` | Verbose / interactive / force / preserve / backup |
| `mv` | Dosya/dizin taşır veya yeniden adlandırır |
| `rm` | Dosya siler |
| `rm -r` / `rm -rf` | Dizini özyinelemeli siler / zorla siler |
| `rmdir` | Sadece boş dizini siler |
| `mkdir` | Dizin oluşturur |
| `mkdir -p` | Ara (parent) dizinleri de oluşturur |
| `touch` | Dosya oluşturur veya zaman damgasını günceller |
| `touch -t` / `-d` / `-r` | Belirli zaman / doğal tarih / referans dosya |
| `file` | Magic number ile gerçek dosya türünü gösterir |
| `file -i` | MIME türünü gösterir |
| `dd if= of=` | Düşük seviyeli girdi→çıktı kopyalama |
| `dd bs= count=` | Blok boyutu ve blok sayısı |
| `/dev/zero` | Sürekli sıfır üreten özel cihaz |
| `find` | Dosya/dizin arar |
| `find -type f/d/l` | Dosya / dizin / sembolik link |
| `find -name` / `-iname` | İsim (duyarlı / duyarsız) |
| `find -size` / `-empty` | Boyuta göre / boş |
| `find -amin/-mmin/-cmin` | Dakika bazlı erişim / değişiklik / durum |
| `find -atime/-mtime/-ctime` | 24 saat periyotlu zaman araması |
| `find -newer` | Referans dosyadan daha yeni |
| `find -exec … {} \;` | Bulunan her öğede komut çalıştırır |
| `find -ls` | Bulunanları uzun liste formatında gösterir |
| `gzip` / `gunzip` | gzip sıkıştırma / açma (`.gz`) |
| `bzip2` / `bunzip2` | bzip2 sıkıştırma / açma (`.bz2`) |
| `xz` / `unxz` | xz sıkıştırma / açma (`.xz`) |
| `tar cf` / `tar xf` | Arşiv oluştur / çıkar |
| `tar cvzf` | Arşiv oluştur + verbose + gzip |
| `tar tf` | Arşiv içeriğini listele |
| `cpio -o` | Dosya listesinden arşiv oluştur (output) |
| `cpio -id` | Arşivden çıkar + gerekirse dizin oluştur |
| `sha256sum` | Kopya doğrulama için hash karşılaştırma |
| `which` | Komutun yolunu gösterir |
