# LPIC-103.3 — Linux Commands Used in This Lesson

## Komutlar

| Komut | Anlamı |
|---|---|
| `ls` | Dizindeki dosya ve dizinleri listeler |
| `cp` | Dosya kopyalar |
| `mv` | Dosya/dizin taşır veya yeniden adlandırır |
| `rm` | Dosya siler |
| `rmdir` | Boş dizini siler |
| `mkdir` | Dizin oluşturur |
| `touch` | Dosya oluşturur veya zaman damgasını günceller |
| `file` | Magic number ile gerçek dosya türünü gösterir |
| `dd` | Düşük seviyeli girdi→çıktı kopyalama |
| `/dev/zero` | Sürekli sıfır üreten özel cihaz |
| `find` | Dosya/dizin arar |
| `gzip` / `gunzip` | gzip sıkıştırma / açma |
| `bzip2` / `bunzip2` | bzip2 sıkıştırma / açma |
| `xz` / `unxz` | xz sıkıştırma / açma |
| `tar` | Arşiv oluştur / çıkar / listele |
| `cpio` | cpio arşivi |
| `sha256sum` | Hash ile kopya doğrulama |

## Seçenekler ve glob (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| bash glob | `*` / `?` / `[ ]` | Joker karakterler |
| `ls` | `-1` / `-l` / `-ltrh` | Tek sütun / uzun / zaman+okunabilir |
| `cp` | `-r` / `-v` / `-i` / `-f` / `-p` / `-b` | Özyinelemeli / verbose / interactive / … |
| `rm` | `-r` / `-rf` | Özyinelemeli / zorla |
| `mkdir` | `-p` | Parent dizinleri de oluştur |
| `touch` | `-t` / `-d` / `-r` | Zaman / tarih / referans |
| `file` | `-i` | MIME türü |
| `dd` | `if=` / `of=` / `bs=` / `count=` | Girdi / çıktı / blok / sayı |
| `find` | `-type f/d/l` | Dosya / dizin / symlink |
| `find` | `-name` / `-iname` | İsim (duyarlı / duyarsız) |
| `find` | `-size` / `-empty` / `-newer` | Boyut / boş / daha yeni |
| `find` | `-amin/-mmin/-cmin` / `-atime/-mtime/-ctime` | Zaman süzgeçleri |
| `find` | `-exec … {} \;` / `-ls` | Bulunanlarda komut / uzun liste |
| `tar` | `cf` / `xf` / `cvzf` / `tf` | Oluştur / çıkar / gzip’li / listele |
| `cpio` | `-o` / `-id` | Output arşiv / extract+dirs |
