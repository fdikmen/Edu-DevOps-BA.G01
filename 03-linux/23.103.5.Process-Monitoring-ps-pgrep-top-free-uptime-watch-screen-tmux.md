# LPIC-103.5 — Process Monitoring (ps, pgrep, top, free, uptime, watch) ve Terminal Multiplexer'lar

## Konu
Süreç yönetiminin ikinci kısmı: **izleme (monitoring)** + kalıcı terminal oturumları (`screen`, `tmux`).

Önceki derste: `jobs`, `fg`/`bg`, `&`, `nohup`, `kill`. Bu derste: süreçleri ve sistem kaynaklarını izleme; SSH kapanınca bile oturumu koruma.

---

## Sinyaller (hatırlatma + genişletme)
`kill -l` → sistemdeki tüm sinyaller.

| Sinyal | No | Anlamı |
|---|---|---|
| `SIGHUP` | 1 | Hangup; çoğu serviste config reload |
| `SIGINT` | 2 | `Ctrl+C` — nazik kesme |
| `SIGKILL` | 9 | Zorla öldür; engellenemez |
| `SIGTERM` | 15 | Varsayılan `kill` — nazik kapanış |
| `SIGCONT` | 18 | Durdurulmuş süreci devam ettir |
| `SIGSTOP` | 19 | `Ctrl+Z` benzeri — dondur (öldürmez) |

```bash
kill -9 <PID>          # veya kill -SIGKILL <PID>
kill -1 %1             # job numarasıyla da sinyal gönderilebilir
```

**Terminated vs Done**
- **Terminated** → süreç bir sinyalle sonlandı (`kill`)
- **Done** → arka plan işi başarıyla bitti / normal kapandı (örn. pencereyi X ile kapatmak)

## ps — Process Listesi
Varsayılan `ps` → **sadece mevcut shell** oturumundaki süreçler (PID, TTY, TIME, CMD).

```bash
ps                  # bu shell
ps -e               # tüm sistem süreçleri
ps -e | wc -l       # kaç süreç
ps -ef              # detaylı (UID, PID, PPID, C, STIME, TIME, CMD)
ps -ef | head
ps aux              # BSD tarzı; %CPU / %MEM de gösterir
ps -ef | grep xclock
ps -ef | grep [x]clock   # grep satırının kendisini elemek için
```

| Sütun | Anlamı |
|---|---|
| `UID` | Çalıştıran kullanıcı |
| `PID` | Process ID |
| `PPID` | Parent Process ID (başlatan süreç) |
| `TTY` | Bağlı terminal (`?` = terminal yok) |
| `TIME` | Kullanılan CPU süresi |
| `CMD` | Komut satırı |

Aynı shell'den başlatılan süreçlerin **PPID**'si aynıdır; her birinin **PID**'si farklıdır.

---

## pgrep — İsme Göre PID
`ps … | grep`'e göre daha temiz; sadece PID basar, grep kendini göstermez.

```bash
pgrep clock
pgrep xeyes
pgrep clock | xargs kill    # bulunan tüm PID'lere kill
```

## top — Canlı Sistem Görünümü
Varsayılan sıralama: **%CPU**. Çıkış: `q` (`Ctrl+C` değil).

Üst satır: saat, **uptime**, kullanıcı sayısı, **load average**.

| Alan | Anlamı |
|---|---|
| `PID` / `USER` | Kimlik / kullanıcı |
| `PR` / `NI` | Priority / niceness |
| `%CPU` / `%MEM` | Kaynak kullanımı |
| `TIME+` | Toplam CPU zamanı |
| `COMMAND` | Komut |

### Load average
Üç sayı: son **1 / 5 / 15** dakika. Yorum **çekirdek sayısına** göre yapılır.

Örn. 4 çekirdek, `6.00, 5.48, 3.25`:
- 15 dk (3.25) → rahat
- 5 dk (5.48) → kapasite aşıldı, kuyruk oluşuyor
- 1 dk (6.00) → 4 çekirdek dolu + ~2 iş bekliyor

8 çekirdekte 6.00 normal; 4 çekirdekte darboğaz; 1–2 çekirdekte kritik. Sorun “yüksek sayı” değil, **çekirdek sayısını aşmak**.

### top kısayolları
| Tuş | İşlev |
|---|---|
| `?` | Yardım |
| `Shift+M` | Memory'ye göre sırala |
| `c` | Tam komut satırını göster |
| `k` | PID sorarak kill (yetki gerekir) |
| `q` | Çık |

Üstte ayrıca Mem / Swap özeti vardır. Yoğun **swap** kullanımı genelde RAM yetersizliği demektir.

## free / uptime / watch

```bash
free -g          # GB
free -h          # human readable (günlük tercih)
uptime           # saat + uptime + user + load average
uptime -p        # pretty (okunabilir)
watch free
watch -n 5 free
watch "df -h | grep sda1"
```

| `watch` seçeneği | Anlamı |
|---|---|
| `-n N` | N saniyede bir yenile (varsayılan ~2) |
| `-b` | Komut hata koduyla bitince bip |
| `-d` | Değişen kısımları vurgula |

## Terminal Multiplexer: screen & tmux
Problem: `komut &` / `nohup` süreç yaşatır ama **terminal ortamını** (pencereler, çıktı, çalışma düzeni) geri getirmez.

**Detach** → oturumdan ayrıl; **reattach** → kaldığın yere dön. SSH kapanır, oturum devam eder.

### screen (prefix: `Ctrl+A`)
```bash
screen
# Ctrl+A d          → detach
screen -ls
screen -r 2742      # reattach
```

| Kısayol | İşlev |
|---|---|
| `Ctrl+A` `c` | Yeni pencere |
| `Ctrl+A` `n` / `p` | Sonraki / önceki pencere |
| `Ctrl+A` `k` | Mevcut pencereyi kapat |
| `Ctrl+A` `d` | Detach |
| `Ctrl+A` `\` | Tüm oturumu kapat (onay ister) |

### tmux (prefix: `Ctrl+B`) — daha modern
```bash
tmux
# Ctrl+B d          → detach
tmux ls
tmux attach -t 0
```

| Kısayol | İşlev |
|---|---|
| `Ctrl+B` `%` | Dikey bölme |
| `Ctrl+B` `"` | Yatay bölme |
| `Ctrl+B` yön tuşları | Bölmeler arası geçiş |
| `Ctrl+B` `c` | Yeni pencere |
| `Ctrl+B` `0`/`1`… | Pencereye atla |
| `Ctrl+B` `d` | Detach |

LPIC için yeterli bilgi: bunlar multiplexer; session oluştur → bağlan → çalıştır → detach → sonra tekrar attach.

## Özet
- Sinyaller: `1` HUP · `2` INT · `9` KILL · `15` TERM · `18` CONT · `19` STOP
- `ps` / `ps -ef` / `ps aux` · `pgrep` · `top` (+ load average / çekirdek)
- `free -h` · `uptime` · `watch`
- `screen` (`Ctrl+A`) · `tmux` (`Ctrl+B`) — kalıcı uzak oturum
