# LPIC-103.2 (İstatistik & Hash) — Linux Commands Used in This Lesson

| Komut | Anlamı |
|---|---|
| `wc` | Dosyadaki satır, kelime ve bayt sayısını gösterir |
| `wc -l` | Yalnızca satır sayısını gösterir |
| `ls -1 \| wc -l` | Dizindeki dosya sayısını satır satır listleyip sayar |
| `sort` | Satırları sıralar (uniq öncesi sık kullanılır) |
| `uniq` | Ardışık tekrar eden satırları tekilleştirir |
| `printf` | Biçimli metin yazar / örnek dosya oluşturur |
| `cat` | Dosya içeriğini ekrana yazdırır |
| `md5sum` | MD5 (128 bit) hash özeti üretir — güvenlik için önerilmez |
| `sha256sum` | SHA-256 (256 bit) hash özeti üretir |
| `sha512sum` | SHA-512 (512 bit) hash özeti üretir |
| `pipe` (`\|`) | Bir komutun çıktısını diğerinin girdisine bağlar |
