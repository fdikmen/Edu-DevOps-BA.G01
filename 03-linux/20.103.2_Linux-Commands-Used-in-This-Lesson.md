# LPIC-103.2 (İstatistik & Hash) — Linux Commands Used in This Lesson

## Komutlar

| Komut | Anlamı |
|---|---|
| `wc` | Satır, kelime ve bayt sayısı |
| `sort` | Satırları sıralar |
| `uniq` | Ardışık tekrarları tekilleştirir |
| `md5sum` | MD5 hash (güvenlik için önerilmez) |
| `sha256sum` / `sha512sum` | SHA-256 / SHA-512 hash |
| `\|` (pipe) | stdout → sonraki stdin (operatör; komut değil) |

## Seçenekler (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| `wc` | `-l` | Yalnız satır sayısı |
