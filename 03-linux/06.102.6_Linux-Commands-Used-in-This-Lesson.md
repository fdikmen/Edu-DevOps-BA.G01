# LPIC-102.6 — Linux Commands Used in This Lesson

| Komut / Sözdizimi | Anlamı |
|---|---|
| `grep -E 'vmx\|svm' /proc/cpuinfo` | Intel VT-x (`vmx`) veya AMD-V (`svm`) bayrağını arar |
| `lscpu \| grep Virtualization` | Sanallaştırma tipini özetler (VT-x / AMD-V) |
| `lsmod \| grep kvm` | Yüklü KVM modüllerini gösterir (`kvm_intel` / `kvm_amd`) |
| `/dev/kvm` | KVM aygıt erişimi (sanallaştırma canlı mı) |
| `sysctl kern.hv_support` | macOS Apple Silicon: Hypervisor framework hazır mı (`1` = evet) |
| `systeminfo` | Windows'ta Hyper-V / sanallaştırma bilgisini gösterir |
| `dbus-uuidgen --ensure` | Benzersiz D-Bus / machine ID oluşturur |
| `rm /etc/machine-id` | Eski machine ID dosyasını siler (klon sonrası) |
| `rm /var/lib/dbus/machine-id` | Eski D-Bus machine ID dosyasını siler |
| `cloud-init` | Bulut örneklerini yapılandırmalı başlatır |
