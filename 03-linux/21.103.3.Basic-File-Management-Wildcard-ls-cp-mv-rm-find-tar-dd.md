# LPIC-103.3 — Temel Dosya Yönetimi (Wildcard, ls, cp, mv, rm, find, tar, dd)

## Konu
LPIC-1 **103.3** (ağırlık: 4) — temel dosya yönetimi. Günlük Linux kullanımında en sık çıkan komutlar: kopyalama, taşıma, silme, joker karakterler, `find`, arşivleme (`tar`/`cpio`) ve düşük seviyeli kopyalama (`dd`).

## Wildcard ve File Globbing
Joker karakterleri **bash** komutu çalıştırmadan önce genişletir (globbing); `cp`/`mv` değil.

| Joker | Anlamı | Örnek |
|---|---|---|
| `*` | Sıfır veya daha fazla karakter | `a*` → apple, archive, app |
| `?` | Tam bir karakter | `??` → iki karakterli isimler; `?a?` → cat, map |
| `[abc]` | a veya b veya c | `file[abc]` → filea, fileb, filec |
| `[a-k]` / `[1-9]` | Aralık | `file[1-9][A-Z]` → file1A, file5B |
| `[!x]` | x hariç herhangi bir karakter | olumsuzlama |

```bash
cp * /tmp
cp a* /tmp
mv ?? /tmp
cp ???.* /tmp          # üç karakter + uzantı (cat.txt, app.sh)
cp file[1-9][A-Z] /tmp
```

## ls — Listeleme
| Komut | Ne yapar |
|---|---|
| `ls` | Dosya/dizin isimlerini listeler |
| `ls -1` | Her satırda bir dosya |
| `ls -l` | Uzun format (izin, sahip, grup, boyut, tarih) |
| `ls -t` | Zamana göre sıralar |
| `ls -r` | Sıralamayı tersine çevirir |
| `ls -h` | Boyutları okunabilir gösterir (4K, 10M) |
| `ls -ltrh` | En yeni altta + uzun + okunabilir — çok sık kullanılan kombinasyon |

## cp — Kopyalama
```bash
cp data.txt /tmp              # aynı isimle kopyala
cp data.txt /tmp/new_data     # yeni isimle kopyala
cp -v data.txt /tmp           # verbose: ne kopyalandığını göster
cp -r project /tmp            # dizin + içeriği (recursive); -r olmadan hata
```
Doğrulama: `sha256sum data.txt` ve `sha256sum /tmp/data.txt`.

## mv — Taşıma / Yeniden Adlandırma
`mv` kopyalamaz; dosyayı taşır. Dizin için `-r` gerekmez.

| Durum | Sonuç |
|---|---|
| Hedef var olan dizin | Dosya/dizin o dizinin içine taşınır |
| Hedef yok | Yeniden adlandırma (`mv B my_new_B_file`) |
| Birden fazla kaynak | Hedef **mutlaka dizin** olmalı |

```bash
mv data.txt /tmp
mv *_* /tmp
mv info note_to_self zeros /tmp
mv directory /tmp
```

## rm — Silme
```bash
rm data.txt
rm -v data.txt          # removed 'data.txt'
rm *.log                # jokerlerle dikkatli!
rmdir empty_dir         # sadece boş dizin
rm -r directory         # dizin + içerik (recursive)
rm -rf directory        # onay istemeden zorla — çok tehlikeli
```
**Uyarı:** `rm -r .` veya `rm -r /` (özellikle `sudo` ile) ciddi veri kaybına yol açar.

### cp / mv üzerine yazma seçenekleri
| Seçenek | Anlamı |
|---|---|
| `-i` | Interactive — üzerine yazmadan önce sor |
| `-f` | Force — onay istemeden üzerine yaz |
| `-b` | Backup — üzerine yazmadan önce yedek al |
| `-p` | Preserve — izin, sahiplik, zaman damgasını koru |

## mkdir / rmdir
```bash
mkdir my_folder
mkdir -p folderA/folderB/folderC   # ara dizinleri de oluştur (parents)
rmdir empty_dir                    # sadece boş
rm -r my_folder                    # dolu dizin için
```

## touch — Dosya / Zaman Damgası
Dosya yoksa oluşturur; varsa içeriği değiştirmeden zaman damgasını günceller.

```bash
touch new_file
touch -t 202601011200 file                    # belirli tarih/saat
touch -d "yesterday 6am" file                 # doğal ifade (macOS'ta çalışmaz)
touch -r /etc/debian_version new_file         # başka dosyadan referans al
```

## file — Gerçek Dosya Türü
Linux uzantıya güvenmez; **magic number** (içerik imzası) ile türü belirler.

```bash
file new_file
file tasks
file /usr/bin/bash          # ELF, 64-bit, dynamically linked...
file -i image.png           # MIME türü + kodlama
```

## dd — Düşük Seviyeli Kopyalama
`if=` (input file), `of=` (output file).

```bash
dd if=tasks of=list_tasks
dd if=/dev/zero of=zero_file bs=1K count=1024   # ~1 MB sıfır dosyası
dd if=/dev/sda of=backup.dd                     # disk yedeği (root; dikkat!)
dd if=backup.dd of=/dev/sda                     # geri yükleme
dd if=/dev/sda | gzip > backup.dd.gz
dd if=ubuntu.iso of=/dev/sdc bs=2K              # bootable USB
```
`/dev/zero` sürekli sıfır üretir. Yanlış cihaz seçimi veri kaybı demektir.

## find — Dosya Arama
```bash
find .                              # mevcut dizin + alt dizinler
find ~ -type d                      # evde sadece dizinler
find . -name "*103*"                # isimde 103 (büyük/küçük harf duyarlı)
find . -iname "*linux*"             # harf duyarsız
find . -type f                      # sadece dosya; d=dizin, l=symlink
```

### Boyut
| Örnek | Anlamı |
|---|---|
| `find . -size 100c` | Tam 100 bayt |
| `find . -size +100k` | 100 KB'dan büyük |
| `find . -size -20M` | 20 MB'dan küçük |
| `find . -size +2G` | 2 GB'dan büyük |
| `find . -empty` | Boş dosya/dizin |

### Zaman
| Önek | Anlamı |
|---|---|
| `a` | Access (erişim) |
| `m` | Modification (içerik değişikliği) |
| `c` | Change (meta: sahip, izin…) |

```bash
find . -mmin -10          # son 10 dakikada değişen
find . -amin -60          # son 60 dakikada erişilen
find . -newer ref_file    # referanstan daha yeni
find . -name "*.txt" -ls
find ~ -mmin -60 -exec echo "bu dosya" {} \;
```
**Not:** `-atime`/`-mtime`/`-ctime` 24 saatlik periyotlarla hesaplanır; `+1` ≈ 48 saatten eski. Daha net kontrol için `-mmin -1440` (1 gün) tercih et.

## Sıkıştırma (tek dosya)
Unix felsefesi: sıkıştırma ≠ arşivleme; araçlar ayrıdır.

| Sıkıştır | Aç | Uzantı |
|---|---|---|
| `gzip tasks` | `gunzip tasks.gz` | `.gz` |
| `bzip2 tasks` | `bunzip2 tasks.bz2` | `.bz2` |
| `xz tasks` | `unxz` / `xz --decompress` | `.xz` |

Metin/log/kod iyi sıkışır; JPEG/MP3 zaten sıkıştırılmış olduğu için kazanç azdır. Küçük dosyalar header nedeniyle büyüyebilir.

## tar — Arşivleme
Arşivleme birleştirir; tek başına sıkıştırmaz. Tire opsiyonel (`tar cf` = `tar -cf`).

```bash
tar cf my_files.tar tasks appear new_file   # oluştur
tar xf my_files.tar                         # çıkar
tar xvf my_files.tar                        # verbose
tar cf backup.tar project_folder            # dizin arşivi
tar cvzf archive.tar.gz files               # arşiv + gzip
tar tf archive.tar                          # içeriği listele (çıkarma)
tar xf archive.tar tasks                    # sadece bir dosya çıkar
```

| Anahtar | Anlamı |
|---|---|
| `c` | create |
| `x` | extract |
| `t` | list |
| `z` | gzip |
| `v` | verbose |
| `f` | arşiv dosya adı |
| `r` | mevcut arşive ekle (append) |

**Güvenlik:** Mutlak yollu arşiv açılırken baştaki `/` kaldırılır (`/etc` → `etc`); gerçek sistem dizinlerinin üzerine yazılması engellenir.

## cpio — Eski Arşivleme
Manyetik teyp döneminden; `find` + pipe ile sık kullanılır.

```bash
# arşiv oluştur (output)
find ... | cpio -o > archive.cpio
# çıkar (input) + gerekirse dizin oluştur
cpio -id < archive.cpio
```

## Özet
- Globbing bash'te yapılır: `*`, `?`, `[]`
- Günlük işlemler: `ls -ltrh`, `cp`/`cp -r`, `mv`, `rm`/`rm -r`, `mkdir -p`
- `touch` zaman damgası; `file`/`file -i` gerçek tür / MIME
- `dd` düşük seviye kopya / disk / USB; `find` güçlü arama + `-exec`
- `gzip`/`bzip2`/`xz` sıkıştırır; `tar` arşivler (`tar czf` ikisini birleştirir); `cpio` eski alternatif
