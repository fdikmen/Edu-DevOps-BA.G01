# LPIC-105.2 — Shell Scripting'e Giriş

## Konu
LPIC **105.2**: Shell scripting temelleri. Hedef: mevcut script'leri özelleştirmek veya basit yeni script yazmak. Dilin her yönüne hakim olmak zorunlu değil; arama, troubleshoot ve öğrenme yeteneği yeterlidir.

Kapsam: `;` / `&&` / `||` · shebang · parametreler · command substitution · `if` / `test` · `read` · `$?` · `for` / `while` · `mail`.

---

## Komutları Birleştirme

| Operatör | Davranış |
|---|---|
| `;` | Soldaki biter → sağdaki **her zaman** çalışır |
| `&&` | Soldaki **başarılı** (exit 0) ise sağı çalıştır |
| `\|\|` | Soldaki **başarısız** (exit ≠ 0) ise sağı çalıştır |
| `&` | Komutu **arka planda** çalıştır — `&&` ile karıştırma |

```bash
cd temp; ls                    # cd başarısız olsa da ls çalışır
cd temp && ls                  # temp yoksa ls çalışmaz
tar -czf backup.tar.gz /home || mail -s "Backup Failed" root <<< "Hata oluştu"
```

- `&&` kısa devre: ilk koşul sağlanmazsa sonrakiler kontrol edilmez.
- `||` kısa devre: ilk komut başarılıysa sağ taraf çalışmaz.
- C'de `&` = bitwise AND, `&&` = logical AND — benzer ayrım.

## Interpreter vs Compiler

| | Interpreter | Compiler |
|---|---|---|
| Ne zaman işler? | Çalıştırma anında | Önceden derler |
| Örnek | `python script.py`, Bash | `gcc program.c -o program` |
| Akış | Kaynak → oku/yorumla → çalıştır | Kaynak → derle → çıktıyı çalıştır |

Shell script'ler **interpreter** ile çalışır; shebang hangi interpreter'ı kullanacağını belirtir.

## Shebang ve İlk Script

**Shebang** (`#!`) — “Bu script'i hangi program çalıştıracak?”
- `#` = hash, `!` = bang → **shebang**
- Bash: `#!/bin/bash`

```bash
mkdir temp
nano my_script.sh
```

```bash
#!/bin/bash
echo "Başlıyor..."
cd temp
touch "$1"
ls -ltr | tail -3
echo "Bitti."
```

```bash
chmod +x my_script.sh          # veya: chmod 755 my_script.sh
./my_script.sh test.txt        # Permission denied → önce chmod
```

`./` zorunlu: Linux mevcut dizini PATH'te aramaz (güvenlik).

| Parça | Anlam |
|---|---|
| `./` | Geçerli dizin |
| `my_script.sh` | Script |
| `test.txt` | 1. parametre → `$1` |

## Script Parametreleri

| Değişken | Anlam |
|---|---|
| `$0` | Script'in kendi adı |
| `$1` | 1. parametre |
| `$2` | 2. parametre |
| `$#` | Toplam parametre sayısı |

```bash
./my_script.sh Tommy           # $1 = Tommy
```

Parametreleri tırnakla kullan: `"$1"`.

## Command Substitution

Bir komutun çıktısını başka yerde kullanma. Önerilen: `$(komut)`.

```bash
bugun=$(date +%Y-%m-%d)
echo "Bugünün tarihi: $bugun"
touch "yedek_$(date +%Y-%m-%d)_$1.tar"
```

Eski biçim: `` `komut` `` (backtick). Okunabilirlik için `$(…)` tercih edilir.

```bash
#!/bin/bash
touch "yedek_$(date +%Y-%m-%d)_$1.tar"
# chmod +x backup.sh && ./backup.sh Tommy
# örn. yedek_2026-09-03_Tommy.tar
```

## Script Çalıştırma Yöntemleri

| Yöntem | Nasıl | Shebang? |
|---|---|---|
| Executable | `chmod +x` + `./script.sh` | OS shebang'e bakar |
| Interpreter | `bash script.sh` / `sh script.sh` | Gerekmez |
| `exec` | Mevcut shell'i komutla **değiştirir** | — |

```bash
bash my_script.sh
exec ping google.com           # shell yerini ping alır; bitince terminal kapanabilir
```

Normal script → **subshell** (yeni child process). `exec` → mevcut shell process'inin yerini alır.

## test, [ ] ve if

`test` koşulu kontrol eder; ekrana yazmaz — sadece **exit status** döner.

```bash
test 5 = 5; echo $?            # 0 → doğru
test 5 = 6; echo $?            # 1 → yanlış

test -e /etc/passwd; echo $?   # dosya/yol var mı
test -d /etc; echo $?          # dizin mi?
```

`[ koşul ]` = `test koşul` — `[` komutunun alternatif sözdizimi (`]` kapanış zorunlu):

```bash
if test -f file.txt; then
  echo "Dosya var"
fi

# aynı şey:
if [ -f file.txt ]; then
  echo "Dosya var"
fi
```

### Genel if sözdizimi
```bash
if [ koşul ]; then
  # true ise
else
  # false ise (opsiyonel)
fi
```

### Uygulama: hello.sh — parametre kontrolü
```bash
#!/bin/bash
if [ $# -ne 1 ]; then
  echo "Error: Please enter exactly one parameter"
  exit 1
fi
echo "Merhaba, $1"
exit 0
```

```bash
chmod +x hello.sh
./hello.sh                     # hata
./hello.sh Alex                # Merhaba, Alex
./hello.sh Alex Sam            # hata (2 parametre)
```

| | Anlam |
|---|---|
| `$# -ne 1` | Parametre sayısı 1'e **eşit değil** (`-ne` = not equal, sayısal) |
| `!=` | String eşit değil |
| `exit 1` | Hata ile çık |
| `exit 0` | Başarılı çıkış |

## Test Operatörleri

| Grup | Operatör | Anlam |
|---|---|---|
| **Dosya** | `-e` | Var mı |
| | `-f` | Normal dosya mı |
| | `-d` | Dizin mi |
| | `-r` / `-w` / `-x` | Okunabilir / yazılabilir / çalıştırılabilir |
| | `-s` | Boyutu > 0 |
| | `-L` | Sembolik link mi |
| **String** | `=` / `!=` | Eşit / eşit değil |
| | `-z` / `-n` | Boş / boş değil |
| **Sayısal** | `-eq` / `-ne` | Eşit / eşit değil |
| | `-lt` / `-le` | Küçük / küçük veya eşit |
| | `-gt` / `-ge` | Büyük / büyük veya eşit |

```bash
[ 50 -gt 40 ]; echo $?         # 0
```

## read — Kullanıcı Girişi

```bash
echo "What's your name?"; read yourName; echo "Merhaba, $yourName"
read -p "What's your name? " yourName; echo "Merhaba, $yourName"
```

| Seçenek | Anlam |
|---|---|
| `-p "metin"` | Prompt'u `read` içinde verir (`echo` gerekmez) |
| `-t saniye` | Maksimum bekleme; süre dolarsa `read` başarısız olur |

```bash
#!/bin/bash
if read -t 10 -p "Enter the server address: " server; then
  echo "Connecting to: $server"
else
  echo "Timeout! Too late."
fi
```

## Dönüş Değerleri (`$?`)

| Exit status | Anlam |
|---|---|
| `0` | Başarılı |
| `1`–`255` | Başarısız / hata |

```bash
ls /var/log/syslog
echo "Dönüş kodu: $?"          # varsa 0; yoksa örn. 2

read -t 3 isim
echo "Dönüş kodu: $?"
```

`read` için tipik kodlar:

| Kod | Anlam |
|---|---|
| `0` | Başarılı girdi |
| `142` | Zaman aşımı (`-t`) |
| `130` | Ctrl+C ile kesildi |

Pratik hata bildirimi:

```bash
./yedekleme_script.sh || echo "Hata!" | mail -s "HATA" root
```

## for Döngüsü

Listedeki her öğe için aynı işlemi tekrarla:

```bash
for degisken in liste
do
  # komutlar
done
```

```bash
for name in Alex Sam Tom
do
  echo "Hello, $name"
done

for myNumber in $(seq 1 5)
do
  echo "Number: $myNumber"
done

for myNumber in {1..5}         # seq yerine kısa yazım
do
  echo "Number: $myNumber"
done

for file in $(ls)
do
  echo "File: $file"
done
```

`seq 1 5` → 1'den 5'e sıralı sayılar üretir.

## while Döngüsü

Koşul **true** olduğu sürece tekrarla:

```bash
while [ koşul ]
do
  # komutlar
done
```

### Uygulama: count.sh
```bash
#!/bin/bash
mycount=5
while [ $mycount -gt 0 ]
do
  echo "Countdown: $mycount"
  let mycount=mycount-1
done
echo "Fire!"
```

```bash
chmod +x count.sh
./count.sh
# Countdown: 5 … 1 → Fire!
```

### let — aritmetik
```bash
let mycount=mycount-1
let mycount+=1                 # kısa yazım
```
`let` içinde değişken başına `$` **konulmaz**: `let sayac+=1` doğru; `let $sayac+=1` değil.

## Root'a E-posta (`mail`)

Çoğu Debian/Ubuntu sisteminde: `sudo apt install mailutils`.

```bash
echo "Backup failed. Please check." | mail -s "Backup Error" root

./backup_script.sh || echo "Backup failed!" | mail -s "ERROR" root
```

| Parça | Rol |
|---|---|
| `echo "…"` | E-posta gövdesi (body) |
| `\|` | Metni `mail`'e aktarır |
| `-s "…"` | Konu (subject) |
| `root` | Alıcı (`root@localhost`) |

**Not:** `mailutils` kurmak yetmeyebilir; yerel/harici MTA yapılandırması da gerekir.

## Özet
- `;` her zaman · `&&` başarıda · `||` hatada · `&` arka plan
- Shebang · `chmod +x` · `./script` · `$0` `$1` `$#` · `$(komut)`
- `test` / `[ ]` · `if … then … fi` · `-eq`/`-ne`/`-gt` … · `-f`/`-d`/`-e`
- `read -p` / `read -t` · `$?` · `exit 0`/`1`
- `for` / `while` · `seq` · `{1..5}` · `let`
- `mail -s` ile root bildirimi

**Sonraki adımlar:** daha karmaşık script'ler, `sed` / `awk`, sistem yönetimi pratikleri. Öğrendiklerini birleştirip basit bir yedekleme script'i yazmayı dene.
