# LPIC-105.2 — Shell Scripting'e Giriş

## Konu
LPIC **105.2**: Shell scripting temelleri. Hedef: mevcut script'leri özelleştirmek veya basit yeni script yazmak. Dilin her yönüne hakim olmak zorunlu değil; arama, troubleshoot ve öğrenme yeteneği yeterlidir.

Bu derste: komut birleştirme (`;`, `&&`, `||`), shebang, script parametreleri, command substitution, çalıştırma yöntemleri, `test` / exit status.

---

## Komutları Birleştirme

| Operatör | Davranış |
|---|---|
| `;` | Soldaki biter → sağdaki **her zaman** çalışır (başarı/başarısızlık fark etmez) |
| `&&` | Soldaki **başarılı** (exit 0) ise sağı çalıştır |
| `\|\|` | Soldaki **başarısız** (exit ≠ 0) ise sağı çalıştır |
| `&` | Komutu **arka planda** çalıştır — `&&` ile karıştırma |

```bash
cd temp; ls                    # cd başarısız olsa da ls çalışır
cd temp && ls                  # temp yoksa ls çalışmaz
tar -czf backup.tar.gz /home || echo "Backup failed"
```

Exit status: başarı → `0`; hata → sıfırdan farklı. Son komutun kodu: `echo $?`.

---

## Interpreter vs Compiler

| | Interpreter | Compiler |
|---|---|---|
| Ne zaman işler? | Çalıştırma anında | Önceden derler |
| Örnek | `python script.py`, Bash script | `gcc program.c -o program` |
| Akış | Kaynak → oku/yorumla → çalıştır | Kaynak → derle → çıktıyı çalıştır |

Shell script'ler **interpreter** ile çalışır; shebang hangi interpreter'ı kullanacağını belirtir.

## Shebang ve İlk Script

**Shebang** (`#!`) — dosyanın ilk satırı; hangi interpreter çalıştıracak?
- `#` = hash, `!` = bang → **shebang**
- Bash için: `#!/bin/bash`

```bash
mkdir temp
nano my_script.sh
```

```bash
#!/bin/bash
echo "Başlıyor..."
cd temp
touch "$1"
ls -ltr | tail -3
echo "Bitti."
```

### Çalıştırılabilir yap + çalıştır
```bash
chmod +x my_script.sh          # veya: chmod 755 my_script.sh
./my_script.sh test.txt        # Permission denied → önce chmod
```

`./` zorunlu: Linux mevcut dizini PATH'te aramaz (güvenlik). Windows'tan farklı bilinçli davranış.

| Parça | Anlam |
|---|---|
| `./` | Geçerli dizin |
| `my_script.sh` | Script |
| `test.txt` | 1. parametre → `$1` |

## Script Parametreleri

| Değişken | Anlam |
|---|---|
| `$0` | Script'in kendi adı |
| `$1` | 1. parametre |
| `$2` | 2. parametre |
| `$#` | Toplam parametre sayısı |

```bash
./my_script.sh Tommy           # $1 = Tommy → touch "$1" → Tommy dosyası
```

Parametreleri tırnakla kullan: `"$1"` — boşluk içeren isimlerde güvenli.

## Command Substitution

Bir komutun çıktısını başka yerde kullanma. Önerilen sözdizim: `$(komut)`.

```bash
bugun=$(date +%Y-%m-%d)
echo "Bugünün tarihi: $bugun"

# dosya adında kullan
touch "yedek_$(date +%Y-%m-%d)_$1.tar"
```

Eski biçim: `` `komut` `` (backtick). Okunabilirlik için `$(…)` tercih edilir.

### Uygulama: backup.sh
```bash
#!/bin/bash
touch "yedek_$(date +%Y-%m-%d)_$1.tar"
```

```bash
chmod +x backup.sh
./backup.sh Tommy
# örn. yedek_2026-09-03_Tommy.tar
```

## Script Çalıştırma Yöntemleri

| Yöntem | Nasıl | Shebang? |
|---|---|---|
| Executable | `chmod +x` + `./script.sh` | OS shebang'e bakar |
| Interpreter ile | `bash script.sh` veya `sh script.sh` | Gerekmez; interpreter açık |
| `exec` | Mevcut shell'i komutla **değiştirir** (yeni process açmaz) | — |

```bash
bash my_script.sh              # shebang olmadan da çalışır
exec ping google.com           # shell yerini ping alır; bitince (Ctrl+C) terminal kapanabilir
```

Normal script çalışması → **subshell** (yeni child process). `exec` → mevcut shell process'inin yerini alır.

## test ve Exit Status

`test` koşulu kontrol eder; ekrana yazmaz — sadece exit status döner.

```bash
test -e /etc/passwd
echo $?                        # 0 → doğru

test -e /abc/xyz
echo $?                        # 1 → yanlış

test -d /etc
echo $?                        # -d → dizin mi?
```

| Seçenek | Anlam |
|---|---|
| `-e` | Dosya/yol var mı |
| `-d` | Dizin mi |

`[ $x = 5 ]` ile `test $x = 5` aynı işi yapar: `[` aslında `test` komutunun alternatif sözdizimidir (`]` kapanış zorunlu).

`if` yapısı bu koşullara göre farklı kod blokları çalıştırır (bir sonraki alt bölümde genişletilir).

## Özet
- `;` her zaman sırayla · `&&` başarıda devam · `||` hatada devam · `&` arka plan
- Shebang `#!/bin/bash` · `chmod +x` · `./script.sh`
- `$0` `$1` `$2` `$#` · command substitution: `$(komut)`
- Çalıştırma: `./` · `bash script` · `exec` (shell'i değiştirir)
- `test` / `[ ]` → exit status · `echo $?`

**Sonraki:** `if` / `else`, döngüler ve daha zengin koşullu akış (transkriptte bu kısım devam ediyor).
