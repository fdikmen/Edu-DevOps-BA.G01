# LPIC-109.2 — Linux Commands Used in This Lesson

Bu ders hostu okumayı, bağlantıyı değiştirmeyi ve ayarın yeniden etkinleşince durduğunu doğrulamayı kapsar. Canlı `ip` / `ifconfig` satırları reboot’ta kaybolur. Kalıcılık dosya veya NetworkManager profilindedir.

## Komutlar ve yollar

| Komut / yol | Anlamı |
|---|---|
| `ip link show` | Arayüzleri, link durumunu ve MAC adreslerini listeler |
| `ip address show` | IPv4/prefix ve IPv6 adreslerini gösterir |
| `ip addr show` | `ip address show` ile aynı aile |
| `ip route show` | Yönlendirme tablosunu gösterir; `default via` varsayılan geçittir |
| `ifconfig` | Eski: up arayüzlerde IP, netmask, MAC ve IPv6. net-tools paketinden gelir |
| `ifconfig -a` | Eski: kapalı aygıtlar dahil bütün arayüzler |
| `sudo ifconfig enp0s8 192.168.1.100 netmask 255.255.255.0` | Geçici IPv4 verir. Ad ve adres hosta göredir |
| `ifconfig eth0 <IP> netmask <netmask>` | Geçici adres sözdizimi. Açılı parantez yazılmaz |
| `ifconfig <aygıt> down` | Aygıtı administratively down yapar |
| `ifconfig <aygıt> up` | IP olmasa da aygıtı açar |
| `/etc/sysconfig/network-scripts/ifcfg-eth0` | Klasik Red Hat: arayüz başına kalıcı dosya |
| `/etc/sysconfig/network` | Klasik Red Hat: `NETWORKING`, `HOSTNAME`, `GATEWAY` |
| `/etc/network/interfaces` | Klasik Debian: bütün arayüzler tek dosyada |
| `ifup eth0` | Dağıtım dosyasını okuyup arayüzü açar |
| `ifdown eth0` | Aynı kaynaktan arayüzü kapatır. Tek kelimedir |
| `ip address add <IP>/<maske> dev eth2` | Arayüze geçici adres ekler |
| `ip address show eth2` | O arayüzün çekirdekteki adresini gösterir |
| `ip address delete <IP>/<maske> dev eth2` | O arayüzden bir adresi siler |
| `ip link set <aygıt> up` | Linki yönetici olarak açar |
| `ip route add default via <IP>` | Varsayılan geçidi ekler |
| `ip route add default via <IP> dev <aygıt>` | Geçidi bir arayüze bağlayarak ekler |
| `nmcli` | NetworkManager özeti: bağlantı, donanım, MTU, IPv4, rota, DNS |
| `nmcli general` | Connectivity ve Wi-Fi bayrakları |
| `nmcli device` | Aygıt durumu: Wi-Fi, loopback, VPN/P2P |
| `nmcli device help` | `device` alt komutlarının yardımı |
| `nmcli <cmd> help` | İlgili alt ailenin yerleşik yardımı |
| `nmcli device wifi` | SSID, kip, kanal, hız ve sinyal |
| `nmcli device wifi connect <SSID> password <parola>` | Terminalden Wi-Fi’ye bağlanır |
| `hostname` | Çalışan adı okur |
| `hostname <isim>` | Geçici ad. `/etc/hostname` değişmez |
| `hostnamectl set-hostname funky-computer` | Kalıcı adı yazar |
| `hostnamectl --pretty set-hostname "Computer in that room"` | Pretty adı yazar |
| `sudo hostname testing` | Transient adı çalışma anında değiştirir |
| `hostnamectl status` | Static, pretty, simge, işletim sistemi, donanım modeli |
| `/etc/hostname` | Kalıcı host adının dosyası |
| `sudo vi /etc/hosts` | Yalnızca bu makinenin IP → ad listesini düzenler |
| `ping server1` | `/etc/hosts` içindeki kısa adı dener |
| `ssh my-dev-server` | Aynı listedeki ada bağlanır |
| `ping google.com` | Önce DNS ile çözer, sonra paketi gönderir |
| `ping -c 2 google.com` | İki paketle çözümleme ve erişimi dener |
| `/etc/resolv.conf` | `nameserver`, `domain`, `search` |
| `/etc/nsswitch.conf` | İsim çözümleme sırası (`hosts: files … dns`) |
| `man nsswitch.conf` | Çözümleme sırasının sayfası |

## Seçenekler, dosya satırları ve çıktı (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| `ifconfig` | `up` | Yalnızca açık arayüzler. `-a` yokken kapalı kart listede görünmez |
| `ifconfig` | `operation not permitted` | Yetki yok; `sudo` gerekir |
| `ifconfig` | `no such device` | Arayüz adı hostta yok |
| `ifcfg-*` | `DEVICE=eth0` | Dosyanın bağlı olduğu arayüz |
| `ifcfg-*` | `ONBOOT=yes` | Açılışta etkinleştir |
| `ifcfg-*` | `TYPE=Ethernet` | Ethernet bağlantısı |
| `ifcfg-*` | `BOOTPROTO=none` | Elle yazılmış statik adres |
| `ifcfg-*` | `IPADDR=192.0.2.10` | Host IPv4 adresi |
| `ifcfg-*` | `NETMASK=255.255.255.0` | Yerel maske |
| `ifcfg-*` | `DNS1=192.0.2.53` | DNS sunucusu |
| `/etc/sysconfig/network` | `NETWORKING=yes` | Hostta ağı aç |
| `/etc/sysconfig/network` | `HOSTNAME=host.example` | Kalıcı ad |
| `/etc/sysconfig/network` | `GATEWAY=192.0.2.1` | Varsayılan geçit |
| `interfaces` | `auto lo` | Loopback açılışta gelsin |
| `interfaces` | `iface lo inet loopback` | Loopback tanımı |
| `interfaces` | `iface eth0 inet static` | Statik IPv4 bloğu |
| `interfaces` | `address` / `netmask` / `gateway` | Adres, maske, geçit |
| `interfaces` | `dns-nameservers` | Bu bloktaki DNS |
| `ip addr` | `127.0.0.1/8` ve `::1/128` | `lo` üzerindeki IPv4 ve IPv6 |
| `ip addr` | `192.0.2.10/24` | Örnek arayüz adresi |
| `ip addr` | `link/ether` | MAC adresi |
| `ip route` | `default via …` | Yerel ağın dışına giden paketlerin sonraki durağı |
| `ip address` | `add` / `delete` | Bir arayüz birden fazla adres taşıyabildiği için ekleme ve silme ayrıdır |
| `nmcli general` | `full` | Connectivity özeti: bağlantı tam |
| `nmcli device wifi` | SSID, channel, rate, signal | Yakındaki yayın |
| `hostnamectl` | static | `/etc/hostname` ile kalan kimlik |
| `hostnamectl` | pretty | Okunabilir etiket |
| `hostnamectl` | transient | Çalışma anındaki kısa ad |
| `/etc/hosts` | `IP` sonra ad | `192.0.2.20 server1` gibi, yalnızca bu makine |
| `resolv.conf` | `nameserver` | İlk susunca sonrakine bakılır |
| `resolv.conf` | `search tommy.net company.com` | `ping tv` → `tv.tommy.net` veya `tv.company.com` |
| `nsswitch.conf` | `hosts: files … dns` | Önce `/etc/hosts`, sonra DNS |
| `nsswitch.conf` | `files` → `systemd` → `sss` | Parola ve kullanıcı kaynaklarının benzer kuyruğu |

## Kalıcı örnekler

Klasik Red Hat arayüz dosyası. Değerler açıklayıcıdır; modern sistemde aynı iş çoğu zaman NetworkManager profilindedir.

```text
DEVICE=eth0
ONBOOT=yes
TYPE=Ethernet
BOOTPROTO=none
IPADDR=192.0.2.10
NETMASK=255.255.255.0
DNS1=192.0.2.53
```

Klasik Red Hat host dosyası:

```text
NETWORKING=yes
HOSTNAME=host.example
GATEWAY=192.0.2.1
```

Klasik Debian:

```text
auto lo
iface lo inet loopback

iface eth0 inet static
    address 192.0.2.10
    netmask 255.255.255.0
    gateway 192.0.2.1
    dns-nameservers 192.0.2.53
```

`/etc/hosts`:

```text
127.0.0.1     localhost
192.0.2.10    tommy-computer
192.0.2.20    server1
192.0.2.30    my-dev-server
```

`/etc/resolv.conf`:

```text
nameserver 192.0.2.53
nameserver 192.0.2.54
domain tommy.net
search tommy.net company.com
```

NetworkManager veya `systemd-resolved` bu dosyayı yeniden üretiyorsa elle yazılan satır durmaz. `systemd-networkd` bazı hostlarda arayüzü ve DNS’i kendisi sahiplenir.
