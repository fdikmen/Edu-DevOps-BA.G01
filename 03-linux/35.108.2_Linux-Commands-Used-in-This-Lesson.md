# LPIC-108.2 — Linux Commands Used in This Lesson

## Komutlar ve yollar

| Komut / yol | Anlamı |
|---|---|
| `ls -l /dev/log` | Yerel log soketini gösterir |
| `/dev/log` | Klasik yerel Unix soketi |
| `/run/systemd/journal/dev-log` | journald’ın dinlediği soket |
| `/run/systemd/journal/syslog` | `ForwardToSyslog=yes` ile rsyslog’a basılan soket |
| `systemctl status rsyslog` | rsyslog durumu |
| `systemctl status systemd-journald` | journald durumu |
| `sudo systemctl restart rsyslog` | rsyslog’u yeniden başlatır (kural uygular) |
| `sudo systemctl restart systemd-journald` | journald’ı yeniden başlatır |
| `ls -l /var/log` | Metin log dizinini listeler |
| `less /var/log/syslog` | Ubuntu/Debian genel sistem kaydı |
| `/var/log/auth.log` | Ubuntu/Debian kimlik doğrulama kaydı |
| `/var/log/messages` | RPM tabanlı genel sistem kaydı |
| `/var/log/secure` | RPM tabanlı kimlik kaydı |
| `/var/log/cron` | cron facility dosyası (her kurulumda yok) |
| `/var/log/kern.log` | kern facility (örnek) |
| `/var/log/mail.log` | mail facility (örnek) |
| `zless` / `zcat` | Sıkıştırılmış log okur |
| `/var/log/wtmp` | Başarılı oturum geçmişi (binary) |
| `/var/log/btmp` | Başarısız girişler (binary) |
| `sudo lastb` | btmp: başarısız giriş denemeleri |
| `journalctl -k` | Journal’daki çekirdek kayıtları |
| `/etc/logrotate.conf` | logrotate ana yapılandırması |
| `/etc/logrotate.d/` | Uygulamaya özel logrotate kuralları |
| `/var/lib/logrotate/status` | Son döndürme durumu |
| `/etc/rsyslog.conf` | rsyslog ana dosyası |
| `/etc/rsyslog.d/` | Ek rsyslog kuralları |
| `/etc/rsyslog.d/50-default.conf` | Ubuntu varsayılan kuralları |
| `logger "mesaj"` | Syslog’a mesaj gönderir |
| `logger -t tag -p facility.priority "mesaj"` | Tag ve öncelikle syslog’a gönderir |
| `journalctl` | Journal’ı açar |
| `journalctl --no-pager` | Sayfalayıcısız basar |
| `journalctl -e` | Sona gider |
| `journalctl -r` | Yeniden eskiye |
| `journalctl -n N` | Son N kayıt |
| `journalctl -f` | Canlı izler |
| `journalctl --list-boots` | Kayıtlı açılışlar |
| `journalctl -b -1` | Önceki açılış |
| `journalctl -u birim` | Birim kayıtları |
| `journalctl --since` / `--until` | Zaman aralığı |
| `journalctl -p düzey` | Öncelik süzgeci |
| `journalctl -t tag` | Identifier / tag |
| `journalctl _PID=…` | PID’e göre süz |
| `systemd-cat` | Doğrudan journal’a yazar |
| `/etc/systemd/journald.conf` | journald saklama ve sınırları |
| `sudo mkdir -p /var/log/journal` | Kalıcı journal dizini |
| `sudo systemd-tmpfiles --create --prefix /var/log/journal` | Journal dizin yapısını oluşturur |
| `journalctl --flush` | Bellekteki kayıtları kalıcı depoya aktarır |
| `/var/log/journal/` | Kalıcı journal |
| `/run/log/journal/` | Geçici journal |
| `journalctl --disk-usage` | Kullanılan alanı gösterir |
| `sudo journalctl --vacuum-time=…` | Süreden eski arşivi siler |
| `sudo journalctl --vacuum-size=…` | Arşiv boyutunu sınırlar |
| `sudo journalctl --vacuum-files=N` | Arşiv dosya sayısını sınırlar |
| `sudo journalctl --rotate` | Aktif dosyayı arşive alır |
| `journalctl --directory=…` | Başka dizindeki journal’ı okur |
| `journalctl --file=…` | Tek journal dosyasını okur |
| `journalctl --root=…` | Bağlanan sistem kökünden okur |
| `journalctl --merge` | Birden fazla kaynağı birlikte okur |

## Seçenekler, yapılandırma ve sözdizimi (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| uzak syslog | `@host` | UDP (port 514); teslim onayı yok |
| uzak syslog | `@@host` | TCP (port 514) |
| logrotate | `weekly` / `rotate N` / `create` / `dateext` | Döndürme sıklığı, kopya sayısı, yeni dosya, tarih eki |
| logrotate | `compress` / `delaycompress` | Sıkıştır / bir tur geciktir |
| logrotate | `missingok` / `notifempty` / `minsize` | Yoksa hata verme / boşsa döndürme / min boyut |
| logrotate | `postrotate` … `endscript` | Döndürme sonrası komut |
| logrotate | `sharedscripts` / `copytruncate` | postrotate bir kez / kopyala-temizle |
| rsyslog | `imuxsock` / `imjournal` / `imudp` / `imtcp` | Girdi modülleri |
| rsyslog | `module(load="imudp")` | imudp yükle |
| rsyslog | `input(type="imudp" port="514")` | UDP 514 dinle |
| rsyslog selector | `facility.priority` | Örn. `auth,authpriv.*`, `*.info`, `kern.*` |
| rsyslog selector | `=info` / `none` / `!` | Tam düzey / hariç tut / olumsuzla |
| rsyslog action | `-` yol başında | Senkron yazma ile ilgili işaret |
| rsyslog action | `*` / kullanıcı adı | Oturum açmış herkese / tek kullanıcıya |
| rsyslog action | `*.crit @IP` / `@@host` | Uzak gönderim |
| facility | `auth` / `authpriv` / `local0`–`local7` | Kimlik / yerel facility’ler |
| priority | `emerg` … `debug` | 0 (en ciddi) … 7 (en hafif) |
| journald.conf | `Storage=` | `volatile` / `persistent` / `auto` / `none` |
| journald.conf | `ForwardToSyslog=` / `ForwardToKMsg=` / … | İletim hedefleri |
| journald.conf | `SystemMaxUse=` / `SystemKeepFree=` / … | Disk sınırları |
| `journalctl -p` | `info` / `err` / `info..info` | info ve üstü / err ve üstü / yalnız info |
| `logger` | `-t` / `-p` | Tag / facility.priority |
| `systemd-cat` | `-t` / `-p` | Tag / priority |
