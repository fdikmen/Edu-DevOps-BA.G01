# LPIC-108.2 — Linux Commands Used in This Lesson

| Komut / Yol / Sözdizimi | Anlamı |
|---|---|
| `ls -l /dev/log` | Yerel log soketini gösterir; çoğu zaman journal soketine kısayoldur |
| `/dev/log` | Klasik yerel Unix soketi; normal dosya değildir |
| `/run/systemd/journal/dev-log` | systemd’de journald’ın dinlediği soket |
| `/run/systemd/journal/syslog` | `ForwardToSyslog=yes` ile journald’ın rsyslog’a bastığı soket |
| `@host` | UDP ile uzak syslog (port 514); teslim onayı yok |
| `@@host` | TCP ile uzak syslog (port 514) |
| `systemctl status rsyslog` | rsyslog çalışıyor mu; Main PID `rsyslogd` |
| `systemctl status systemd-journald` | journald çalışıyor mu |
| `sudo systemctl restart rsyslog` | rsyslog kuralını uygular |
| `sudo systemctl restart systemd-journald` | journald ayarını uygular |
| `ls -l /var/log` | Metin log dizinini listeler |
| `less /var/log/syslog` | Ubuntu/Debian genel sistem kaydı |
| `/var/log/auth.log` | Ubuntu/Debian kimlik doğrulama kaydı |
| `/var/log/messages` | RPM tabanlı genel sistem kaydı |
| `/var/log/secure` | RPM tabanlı kimlik kaydı |
| `/var/log/cron` | cron facility dosyası; her kurulumda yoktur |
| `/var/log/kern.log` | kern facility (Ubuntu kural örneği) |
| `/var/log/mail.log` | mail facility (Ubuntu kural örneği) |
| `/var/log/apache2/` | Apache’nin kendi access/error logları; rsyslog ürünü olmak zorunda değildir |
| `grep` | Metin log içinde arama |
| `zless` / `zcat` | Sıkıştırılmış logu okur |
| `/run/utmp` | Şu anki oturumlar (binary). 108.2 resmî listesinde yok |
| `/var/log/wtmp` | Başarılı oturum geçmişi (binary) |
| `/var/log/btmp` | Başarısız girişler (binary); okumak için root gerekebilir |
| `who` / `w` | utmp: şu anda kim açık (110.1) |
| `last` | wtmp: başarılı geçmiş (110.1) |
| `sudo lastb` | btmp: başarısız denemeler |
| `sudo dmesg \| less` | Çekirdek halka tamponu (101.2). `less` içinde Shift+G sona gider |
| `journalctl -k` | Journal’daki çekirdek kayıtları; güncel açılış (108.2) |
| `/etc/logrotate.conf` | logrotate ana yapılandırması |
| `/etc/logrotate.d/` | Uygulamaya özel logrotate kuralları |
| `/var/lib/logrotate/status` | Hangi dosyanın en son ne zaman döndüğü |
| `less /etc/logrotate.conf` | Ana döndürme dosyasını okur |
| `weekly` | Her hafta döndür |
| `rotate 4` | En fazla 4 eski kopya; yenisi gelince en eskisi silinir |
| `create` | Döndürünce yeni boş dosyayı sahip, grup ve izinle açar |
| `dateext` | Arşiv adına tarih koyar |
| `compress` | Eski dosyayı sıkıştırır |
| `delaycompress` | Sıkıştırmayı bir sonraki tura erteler |
| `missingok` | Dosya yoksa hata verme |
| `notifempty` | Dosya boşsa döndürme |
| `minsize 1M` | Bu boyuta gelmeden döndürme |
| `postrotate` … `endscript` | Döndürme bitince komut (ör. rsyslog’a HUP) |
| `sharedscripts` | postrotate’i her dosya için değil, bir kez çalıştırır |
| `copytruncate` | Kopyala, sonra dosyanın içini temizle; arada kayıt kaybolabilir |
| `SIGHUP` / HUP | Servise yapılandırmayı yeniden oku / yeni log dosyasını aç |
| `/etc/rsyslog.conf` | rsyslog ana dosyası: Modules, Global directives, Rules |
| `/etc/rsyslog.d/` | Ek rsyslog kuralları |
| `/etc/rsyslog.d/50-default.conf` | Ubuntu varsayılan kuralları (Rules çoğu zaman burada) |
| `less /etc/rsyslog.conf` | Ana rsyslog dosyasını okur |
| `less /etc/rsyslog.d/50-default.conf` | Varsayılan selector/action satırlarını okur |
| `sudo nano /etc/rsyslog.conf` | Yapılandırmayı düzenler |
| `imuxsock` | Unix soketinden yerel syslog alır |
| `imjournal` | Journal’dan doğrudan okur; `Storage=none` olmamalı |
| `imudp` | UDP ile syslog kabul eder |
| `imtcp` | TCP ile syslog kabul eder |
| `$ModLoad imudp` / `$UDPServerRun 514` | Eski sözdizimi: UDP sunucu, port 514 |
| `module(load="imudp")` | Güncel: imudp yükle |
| `input(type="imudp" port="514")` | Güncel: UDP 514 dinle |
| `$FileOwner` / `$FileGroup` / `$FileCreateMode` | Yeni log dosyasının sahibi, grubu, izni |
| `$IncludeConfig` / `include()` | Ek yapılandırma dosyalarını okur |
| `facility.priority` | Selector biçimi |
| `auth,authpriv.*` | İki facility, bütün priority’ler → örnekte `/var/log/auth.log` |
| `*.info` | Bütün facility’ler, info ve daha ciddi; debug hariç |
| `=info` | Yalnızca tam info |
| `none` | O facility’yi selector dışında bırakır |
| `!` | Selector olumsuzlaması |
| `,` | Facility ayırıcı |
| `;` | Selector ayırıcı |
| `*.*;auth,authpriv.none` | Her şey, auth/authpriv hariç → `-/var/log/syslog` |
| `kern.*` | kern, bütün düzeyler → `-/var/log/kern.log` |
| `-` dosya yolunun başında | Zorunlu senkron yazmayla ilgili; "geciktirir" diye genellenmez |
| `*` (action) | Oturum açmış bütün kullanıcılara |
| kullanıcı adı (action) | O kullanıcı giriş yapmışsa terminaline |
| `*.crit @192.0.2.10` | crit ve daha ciddiyi UDP ile gönder |
| `*.crit @@log.example.com` | Aynı seçimi TCP ile gönder |
| `auth` / `authpriv` | Genel kimlik / hassas kimlik; aynı facility değeri değildir |
| `security` | `auth`’un eski adı; kullanılmamalı |
| `local0`–`local7` | Kuruma ayrılmış 8 yerel facility; local7 dahildir |
| `emerg` (`panic`) … `debug` | Priority 0 (en ciddi) … 7 (en hafif) |
| `logger "mesaj"` | Syslog’a mesaj verir; dosyaya doğrudan yazmaz |
| `logger -t ders -p local0.info "mesaj"` | Tag ve facility.priority ile gönderir |
| `uname -a \| logger -t ders` | Komut çıktısını syslog’a iletir |
| `journalctl` | Journal’ı sayfalayıcıda açar; çıkış `q` |
| `journalctl --no-pager` | Sayfalayıcısız basar |
| `journalctl -e` | Sona gider |
| `journalctl -r` | Yeniden eskiye |
| `journalctl -n 10` | Son 10 kayıt |
| `journalctl -f` | Canlı izler; çıkış Ctrl+C |
| `journalctl --list-boots` | Kayıtlı açılışlar: `0` şimdi, `-1` önceki |
| `journalctl -b -1` | Bir önceki açılış; journal kalıcı değilse boş olabilir |
| `journalctl -u ssh.service` | Birimin kayıtları (`sshd.service` de olabilir) |
| `journalctl -b -u ssh.service` | Yalnız bu açılıştaki birim |
| `journalctl --since` / `--until` | Zaman aralığı; `yesterday`, `today`, `now`, `10 minutes ago` |
| `journalctl -p info` | info ve daha ciddi (0–6); yalnız info değil |
| `journalctl -p err` | err ve daha ciddi |
| `journalctl -p info..info` | Yalnız tam info |
| `journalctl -t sshd` | Identifier / tag (`--identifier`) |
| `journalctl _PID=1234` | Kaydı yazan sürecin PID’i |
| `echo "…" \| systemd-cat` | Satırı doğrudan journal’a yazar |
| `systemd-cat -t ders -p info echo "deneme"` | Tag ve priority ile journal’a |
| `systemd-cat -t ders uname -a` | Komut çıktısını doğrudan journal’a |
| `/etc/systemd/journald.conf` | journald saklama ve sınırları |
| `Storage=volatile` | `/run/log/journal`; reboot’ta gider |
| `Storage=persistent` | `/var/log/journal`; diskte kalır |
| `Storage=auto` | `/var/log/journal` varsa kalıcı, yoksa volatile |
| `Storage=none` | Journal deposuna yazma; `ForwardToSyslog=` ile syslog’a gidebilir |
| `ForwardToSyslog=yes` | journald → syslog soketi |
| `ForwardToKMsg=` | Çekirdek tamponuna |
| `ForwardToConsole=` | Konsola |
| `ForwardToWall=` | Oturum açmış kullanıcılara |
| `sudo mkdir -p /var/log/journal` | Kalıcı journal dizinini açar |
| `sudo systemd-tmpfiles --create --prefix /var/log/journal` | Dizin yapısını oluşturur |
| `journalctl --flush` | Bellekteki kayıtları kalıcı depoya aktarır |
| `cat /etc/machine-id` | Journal alt klasörünün adı |
| `/var/log/journal/` | Kalıcı journal; alt dizin machine-id |
| `/run/log/journal/` | Geçici journal |
| `system.journal` | Sistem kayıtları (binary) |
| `user-1000.journal` | O kullanıcının kayıtları |
| `system@…` | Döndürülmüş eski journal dosyası |
| `SystemMaxUse=` | Kalıcı journal’ın toplam alanı (ör. `100M`) |
| `SystemKeepFree=` | Diskte boş bırakılacak alan |
| `SystemMaxFileSize=` | Tek journal dosyasının üst boyutu |
| `SystemMaxFiles=` | Saklanacak journal dosyası sayısı |
| `RuntimeMaxUse` / `RuntimeKeepFree` / `RuntimeMaxFileSize` / `RuntimeMaxFiles` | `/run` altındaki journal için aynı sınırlar |
| `man journald.conf` | O sürümdeki varsayılan sınırlar |
| `journalctl --disk-usage` | Kullanılan alanı gösterir; silmez |
| `sudo journalctl --vacuum-time=2weeks` | Süreden eski arşivi siler (`2weeks`, `10min`, `1month`; tek `m` yok) |
| `sudo journalctl --vacuum-size=200M` | Arşiv boyutunu sınırlar |
| `sudo journalctl --vacuum-files=5` | En fazla bu kadar arşiv dosyası bırakır |
| `sudo journalctl --rotate` | Aktif dosyayı arşive alır; vacuum aktif dosyayı silmez |
| `journalctl --directory=/mnt/var/log/journal` | Bağlı diskteki journal dizinini okur |
| `journalctl --file=…/system.journal` | Tek journal dosyasını okur |
| `journalctl --root=/mnt` | Bağlanan sistemin kökü; journal dizinini bunun altında arar |
| `journalctl --merge` | Birden fazla kaynağı birlikte okur; yeni journal’a yazmaz |
