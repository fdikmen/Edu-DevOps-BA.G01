# LPIC-108.1 — Linux Commands Used in This Lesson

## Komutlar ve yollar

| Komut / yol | Anlamı |
|---|---|
| `date` | Sistem tarih ve saatini gösterir |
| `date -s "YYYY-MM-DD HH:MM:SS"` | Sistem saatini ayarlar (root); RTC’ye yazmaz |
| `sudo hwclock` | Donanım saatini (RTC) gösterir |
| `hwclock --systohc` / `hwclock -w` | Sistem saatini donanım saatine yazar |
| `hwclock --utc` / `--localtime` | RTC’nin UTC mi yerel saat mi tutulduğunu belirtir |
| `timedatectl` | Saat, dilim, RTC biçimi, NTP durumu |
| `sudo timedatectl set-ntp true` | Ağ zaman senkronizasyonunu açar |
| `sudo timedatectl set-timezone BÖLGE` | Sistem saat dilimini ayarlar |
| `/etc/adjtime` | RTC drift; son satır `UTC` veya `LOCAL` |
| `/etc/timezone` | Bazı dağıtımlarda dilim adı (düz metin) |
| `/etc/localtime` | Asıl dilim dosyası; zoneinfo’ya symlink |
| `/usr/share/zoneinfo/` | Saat dilimi verileri |
| `ls -l /etc/localtime` | Dilim linkinin hedefini gösterir |
| `ln -s /usr/share/zoneinfo/… /etc/localtime` | Dilimi symlink ile bağlar |
| `ntpd` | Klasik NTP arka plan servisi |
| `/etc/ntp.conf` | ntpd yapılandırması |
| `ntpdate sunucu` | Saati bir NTP sunucusuyla elle eşitler (eski) |
| `ntpq -p` | NTP eşlerini, offset ve delay gösterir |
| `sudo apt install ntpsec` | `ntpq` için (dağıtıma göre) |
| `chrony` / `chronyd` | Modern NTP istemcisi |
| `/etc/chrony/chrony.conf` | Ubuntu chrony yapılandırması |
| `/etc/chrony.conf` | Bazı dağıtımlarda chrony yapılandırması |
| `systemctl status chrony` | chrony servisi |
| `chronyc tracking` | Senkron, drift, leap status |
| `chronyc activity` | Kaynak etkinliği |
| `chronyc sources` | chrony kaynak listesi |
| `chronyc -h sunucu activity` | Uzak chrony’yi izler |
| `systemd-timesyncd` | systemd zaman senkron servisi |

## Seçenekler, yapılandırma ve çıktı (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| `timedatectl` çıktısı | `RTC in local TZ: no` / `yes` | Donanım saati UTC / yerel |
| `/etc/ntp.conf` | `pool …` + `iburst` | Havuz; başlangıçta hızlı senkron istekleri |
| `ntpq -p` çıktısı | `*` | Seçilen (sys.peer) kaynak |
| chrony | `pool.ntp.org` | Genel NTP sunucu havuzu örneği |
