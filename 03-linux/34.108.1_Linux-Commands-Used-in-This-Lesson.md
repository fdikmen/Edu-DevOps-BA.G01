# LPIC-108.1 — Linux Commands Used in This Lesson

| Komut / Yol / Sözdizimi | Anlamı |
|---|---|
| `date` | Sistem tarih ve saatini gösterir |
| `date -s "YYYY-MM-DD HH:MM:SS"` | Sistem saatini ayarlar (root); RTC'ye yazmaz |
| `sudo hwclock` | Donanım saatini (RTC) gösterir |
| `hwclock --systohc` / `hwclock -w` | Sistem saatini donanım saatine yazar |
| `hwclock --utc` / `--localtime` | RTC'nin UTC mi yerel saat mi tutulduğunu belirtir |
| `timedatectl` | Saat, saat dilimi, RTC biçimi, NTP durumu |
| `RTC in local TZ` = `no` / `yes` | Donanım saati UTC / yerel saat |
| `sudo timedatectl set-ntp true` | Ağ zaman senkronizasyonunu açar |
| `sudo timedatectl set-timezone BÖLGE` | Sistem saat dilimini ayarlar |
| `/etc/adjtime` | RTC drift; son satır `UTC` veya `LOCAL` (dosya olmayabilir) |
| `/etc/timezone` | Bazı dağıtımlarda dilim adı (düz metin) |
| `/etc/localtime` | Asıl dilim dosyası; zoneinfo'ya symlink |
| `/usr/share/zoneinfo/` | Saat dilimi verileri (binary) |
| `ls -l /etc/localtime` | Dilim linkinin hedefini gösterir |
| `file /usr/share/zoneinfo/Asia/Tehran` | zoneinfo dosyasının türünü söyler |
| `unlink /etc/localtime` | Dilim linkini kaldırır (sonra `date` UTC gösterebilir) |
| `ln -s /usr/share/zoneinfo/… /etc/localtime` | Dilimi symlink ile bağlar (tam yol; kopya değil) |
| `pool.ntp.org` | Genel NTP sunucu havuzu |
| `ntpd` | NTP'nin orijinal arka plan servisi |
| `/etc/ntp.conf` | ntpd yapılandırması (pool + `iburst`) |
| `iburst` | Başlangıçta kısa aralıklarla çok istek; senkronu hızlandırır |
| `ntpdate pool.ntp.org` | Saati bir NTP sunucusuyla elle eşitler (eski; yeni Ubuntu'da kurulu olmayabilir) |
| `ntpq -p` | NTP eşlerini, offset ve delay gösterir (`*` seçilen) |
| `sudo apt install ntpsec` | `ntpq` yoksa (ntpdate ile ntpd aynı anda kurulmaz) |
| `chrony` / `chronyd` | Modern NTP istemcisi; saati zıplatmadan (slewing) düzeltir |
| `/etc/chrony/chrony.conf` | Ubuntu chrony yapılandırması |
| `/etc/chrony.conf` | Bazı dağıtımlarda chrony yapılandırması |
| `systemctl status chrony` | chrony servisi ve seçilen kaynak |
| `chronyc tracking` | Senkron, drift, leap status |
| `chronyc activity` | Kaynak etkinliği |
| `chronyc sources` | chrony kaynakları (`ntpq -p` mantığı) |
| `chronyc -h sunucu activity` | Uzak chrony'yi izler; değişiklik yapmaz |
| `systemd-timesyncd` | Ubuntu 25.10 öncesi tipik zaman senkron servisi |
