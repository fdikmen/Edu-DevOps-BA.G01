# LPIC-104.5 — Linux Commands Used in This Lesson

## Komutlar ve yollar

| Komut / yol | Anlamı |
|---|---|
| `whoami` | Geçerli kullanıcı adı |
| `groups` | Üye olunan gruplar |
| `id` | UID, GID, groups |
| `sudo su` | Root shell (UID 0) |
| `cat /etc/passwd` | Kullanıcı hesap bilgileri |
| `sudo cat /etc/shadow` | Parola hash’leri |
| `cat /etc/group` | Gruplar ve üyeler |
| `getent group` | Sistem gruplarını listele |
| `ls -l` / `ls -ld` | İzinler + owner/group (dizin için `-d`) |
| `chmod` | İzin değiştir |
| `chown` | Owner değiştir |
| `chgrp` | Group ownership değiştir |
| `adduser` / `deluser` | Kullanıcı ekle / sil |
| `groupadd` / `groupdel` | Grup ekle / sil |
| `usermod` | Kullanıcıyı değiştir |
| `newgrp group` | Shell’in etkin grubunu değiştir |
| `umask` / `umask NNN` | Varsayılan maskeyi gör / ayarla |
| `which passwd` · `ls -l /usr/bin/passwd` | SUID örneği (`-rws…`) |
| `ls -ld /tmp` | Sticky örneği (`…rwt`) |

## Seçenekler ve kip (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| `chmod` | oktal (`755`) / sembolik (`u+x`, `g+w`, `o-r`) | İzin biçimleri |
| `chmod` | `-R` | Özyinelemeli |
| `chmod` | `u+s` / `u-s` / `4000` | SUID |
| `chmod` | `g+s` / `g-s` / `2000` | SGID |
| `chmod` | `+t` / `-t` / `1000` | Sticky bit |
| `chmod` | `4755` / `2770` / `1777` | Special + normal birleşim |
| `chown` | `user:group` | Owner + group birlikte |
| `usermod` | `-aG group user` | Supplementary gruba ekle (`-a` şart) |
| `usermod` | `-g group user` | Primary group |
| `deluser` | `--remove-home` | Home ile birlikte sil |
