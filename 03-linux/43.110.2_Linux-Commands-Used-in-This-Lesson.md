# LPIC-110.2 — Linux Commands Used in This Lesson

Bu ders parola kasasını, kabuk kilidini, süper sunucuyu, TCP wrapper dosyalarını ve kullanılmayan servisi kapsar. `hosts.allow` / `hosts.deny` yalnız `libwrap` bağlı programlarda işler. Socket denemesi, kesilmesi sorun olmayan bir laboratuvar SSH oturumunda yapılır. FTP alıştırması kendi kurduğun `vsftpd` üzerindedir.

## Komutlar ve yollar

| Komut / yol | Anlamı |
|---|---|
| `cat /etc/passwd` | Herkes okur. Parola alanında `x`, artı UID, ad, ev, kabuk |
| `cat /etc/shadow` | Normal hesapta izin hatası. Özet root’tadır |
| `sudo useradd -m testuser` | Deneme hesabı ve ev dizini |
| `sudo passwd testuser` | Hesabın parolasını koyar |
| `grep testuser /etc/passwd` | Kabuk alanını gösterir |
| `sudo usermod -s /usr/sbin/nologin testuser` | Etkileşimli kabuğu kapatır |
| `ssh -N testuser@sunucu` | Kabuksuz tünel. `nologin` bunu tek başına kesmeyebilir |
| `sudo passwd -l testuser` | Parola özetini kilitleyerek hesabı kilitler |
| `sudo vim /etc/nologin` | Genel girişi kapatan dosyayı ve mesajı oluşturur |
| `ss -tuln` | Sayısal dinleyen TCP/UDP |
| `netstat -tlpn` | Dinleyen TCP, PID. Eski araç |
| `lsof -i :port` | O porttaki ağ dosyası |
| `ldd /usr/sbin/vsftpd \| grep libwrap` | TCP wrapper kütüphanesi var mı |
| `fuser 22/tcp -v` | 22/tcp’yi tutan PID |
| `systemctl stop ssh.service` | sshd portu bırakır. Birim adı `sshd` olabilir |
| `systemctl start ssh.socket` | Portu systemd (PID 1) dinler |
| `systemctl stop ssh.socket` | Socket aktivasyonunu keser |
| `systemctl start ssh.service` | Geleneksel dinlemeye döner |
| `sudo service --status-all` | Eski servis durum listesi |
| `systemctl status` | Unit durumu |
| `systemctl list-units --all --state=active --type=service,socket` | Aktif servis ve soket |
| `sudo chkconfig vsftpd off` | Red Hat: SysV servisi açılışta kapalı |
| `sudo update-rc.d vsftpd remove` | Debian: rc başlatma bağlarını kaldırır |
| `sudo systemctl stop vsftpd` | Servisi şimdi durdurur |
| `sudo systemctl disable vsftpd` | Bir sonraki açılışta başlatmaz |
| `sudo systemctl disable --now vsftpd` | Hem şimdi durdurur hem açılıştan çıkar |
| `/etc/passwd` | Dünya okunur hesap listesi, alanda `x` |
| `/etc/shadow` | Tuzlu özet ve yaşlandırma |
| `/usr/sbin/nologin` | Girişte çalışıp çıkan kabuk |
| `/etc/nologin` | Varken herkesin girişini keser. Silinince açılır |
| `/etc/xinetd.conf` | Süper sunucu ana dosyası |
| `/etc/xinetd.d/` | Servis başına xinetd parçası |
| `/etc/hosts.allow` | Wrapper izin listesi. Önce bu okunur |
| `/etc/hosts.deny` | Wrapper red listesi |
| `/etc/init.d/` | System V başlatma betikleri |
| `/etc/inittab` | `id:runlevels:action:process` |
| `/etc/rc.d/init.d` | Red Hat SysV betik yolu |

## Seçenekler, alanlar ve çıktı (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| `passwd` | `x` | Özet bu dosyada değil |
| `shadow` | `-rw-r-----` | Sahip ve grup okur; diğerleri okuyamaz |
| `usermod -s` | kabuk yolu | Hesabın giriş programı |
| `ssh -N` | tünel | Uzak komut yok |
| `passwd -l` | kilit | Özeti geçersiz kılar |
| `/etc/nologin` | dosyanın varlığı | İçi boşalsa da giriş kapalı kalır |
| port | &lt; 1024 | root veya `CAP_NET_BIND_SERVICE` |
| port | ≥ 1024 | Sıradan yerel kullanıcı bağlayabilir |
| port | 22 / 80 / 443 | SSH / HTTP / HTTPS |
| `xinetd` | `disable = no` | Servis parçası açık |
| `xinetd` | `socket_type = stream` | TCP |
| `xinetd` | `server` | Çalıştırılacak program |
| `xinetd` | `no_access` | Reddedilen ağ |
| `xinetd` | `access_times` | İzinli saat aralığı |
| `ldd` | `libwrap.so` | Daemon, allow/deny dosyalarına bakar |
| allow sonra deny | eşleşme yok | İkisinde de yoksa erişim açık kalır |
| `ssh.socket` | PID 1 | Dinleyen `systemd`; bağlantı servise verilir |
| `systemctl stop` | şimdi | Süreç biter, açılış ayarı durur |
| `systemctl disable` | açılış | Çalışan süreci tek başına kesmez |
| `disable --now` | ikisi | Durdur ve açılıştan çıkar |
| `chkconfig` | `off` | Red Hat açılış bağı |
| `update-rc.d` | `remove` | Debian rc sembolik bağları |
| `inittab` | `id:3:initdefault:` | Varsayılan runlevel 3 |
| `inittab` | `respawn` | Süreç ölünce yeniden başlat |

## Örnek akış

Kabuğu kapat, hesabı kilitle, genel girişi açıp geri al:

```text
grep testuser /etc/passwd
sudo usermod -s /usr/sbin/nologin testuser
sudo passwd -l testuser
sudo vim /etc/nologin
# girişler kapalı. Açmak için dosyanın kendisi silinir.
```

Wrapper desteği ve dinleyici:

```text
ldd /usr/sbin/vsftpd | grep libwrap
ss -tuln
fuser 22/tcp -v
```

Servisi şimdi ve açılışta kapat:

```text
systemctl list-units --all --state=active --type=service,socket
sudo systemctl disable --now vsftpd
```
