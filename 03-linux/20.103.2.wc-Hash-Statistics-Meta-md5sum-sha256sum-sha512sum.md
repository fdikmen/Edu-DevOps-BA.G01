# LPIC-103.2 (Son Bölüm) — İstatistik, Meta Bilgi ve Hash (wc, md5sum, sha256sum, sha512sum)

## Konu
103.2 metin işleme konusunun son bölümü: dosyalardan **istatistik / meta bilgi** almak (`wc`) ve dosya özeti çıkaran **hash** değerleri (`md5sum`, `sha256sum`, `sha512sum`).

103.2 dört parçaya ayrılmıştı: görüntüleme → bölüm seçme → değiştirme (sort/uniq/sed) → istatistik ve hash. Bu dosya son parçayı özetler.

## wc — Satır, Kelime, Bayt Sayısı
`wc` (word count) bir dosyadaki satır, kelime ve bayt/karakter sayısını gösterir.

```bash
printf "Ubuntu\nFedora\nUbuntu\nArch\nDebian\nFedora\nMint\nArch\n" > distros
sort distros | uniq > unique_distros
wc unique_distros    # örn. 5 5 31 unique_distros
wc distros           # örn. 8 8 50 distros
```

| Çıktı sırası | Anlamı |
|---|---|
| 1. sayı | Satır sayısı |
| 2. sayı | Kelime sayısı |
| 3. sayı | Bayt boyutu |

- Benzersiz listede `wc` → kaç farklı dağıtım önerildiği
- Orijinal listede `wc` → toplam kaç öneri olduğu (tekrarlar dahil)

### Sadece satır sayısı: `wc -l`
```bash
wc -l unique_distros
ls -1 | wc -l        # dizindeki dosya sayısı
```
**Bul + Say = pipeline mantığı:** önce veriyi üret (`ls -1`), sonra analiz et (`wc -l`).

| Komut | Ne yapar |
|---|---|
| `wc dosya` | Satır + kelime + bayt |
| `wc -l dosya` | Sadece satır sayısı |
| `ls -1 \| wc -l` | Dizindeki dosya sayısı |

## Hash Nedir?
**Kriptografik hash**, bir girdiyi (dosya, metin, veri) alıp **sabit uzunlukta** benzersiz bir özet değer üreten matematiksel fonksiyondur.

```bash
printf 'Hello Linux\n' > message
sha256sum message
# Aynı dosyada tekrar → aynı hash (deterministik)
printf 'Hello Linux!\n' > message   # zsh'de ! için tek tırnak kullan
sha256sum message                   # küçük değişiklik → tamamen farklı hash
```

### Hash özellikleri
1. **Deterministik** — aynı veri → aynı hash; küçük değişiklik → farklı hash
2. **Tek yönlü** — hash'ten orijinal veriyi geri bulmak pratikte imkânsız
3. **Sabit boyut** — girdi ne kadar büyük olursa olsun çıktı sabittir

## Yaygın Hash Komutları (LPIC)

```bash
printf "Linux Hash Test\n" > file
md5sum file
sha256sum file
sha512sum file
```

| Komut | Algoritma | Hash uzunluğu | Not |
|---|---|---|---|
| `md5sum` | MD5 | 128 bit | Eski; güvenlik için önerilmez |
| `sha256sum` | SHA-256 | 256 bit | Yaygın, güvenli |
| `sha512sum` | SHA-512 | 512 bit | Daha uzun / daha güvenli |

SHA = Secure Hash Algorithm.

## Gerçek Hayat Kullanım Alanları

### 1. Dosya bütünlüğünü doğrulamak
İndirilen ISO / paylaşılan dosya için yayıncının verdiği hash ile kendi hesapladığın değeri karşılaştır:
```bash
sha256sum linux.iso
```
Aynıysa dosya bozulmamış / değiştirilmemiş demektir. (Örn. Fedora indirme sayfasındaki SHA256 checksum.)

### 2. Parolaları güvenli saklamak
Siteler parolayı düz metin tutmaz; hash'ini kaydeder. Girişte girilen parolanın hash'i veritabanındakiyle karşılaştırılır — site gerçek parolayı bilmeden kimlik doğrular.

## Özet
- `wc` / `wc -l` → istatistik; `ls -1 | wc -l` → dosya sayısı
- Hash → sabit uzunlukta özet; bütünlük kontrolü ve parola saklama
- LPIC için: `md5sum`, `sha256sum`, `sha512sum` — mümkünse SHA ailesini tercih et
- Bu bölümle 103.2 metin işleme konusu tamamlanır: görüntüleme → seçme → değiştirme → istatistik/özet
