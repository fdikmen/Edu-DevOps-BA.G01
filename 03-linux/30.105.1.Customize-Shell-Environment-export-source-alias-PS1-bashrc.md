# LPIC-105.1 — Shell Ortamını Özelleştirme ve Kullanma

## Konu
LPIC **102** sınavının başlangıcı — **105.1**: Bash shell ortamını yapılandırma. LPIC seviyesinde script yazmak değil; basit script okuyup değiştirebilmek yeterli. (105.2 → scripting temelleri, sonraki ders.)

| Terim | Anlamı |
|---|---|
| **Shell** | Komutları yorumlayan program (Bash) |
| **Terminal** | Shell'e eriştiğin arayüz — shell ≠ terminal |
| **Shell scripting** | Komutların dosyada sırayla/koşullu çalıştırılması |

LPIC odak: **Bash** (Bourne Again Shell). macOS varsayılanı zsh olsa da temel kavramlar benzer.

Diğer shell'ler: `sh`, `zsh`, `csh`, `ksh`.

---

## Değişkenler

```bash
name=Tommy                    # = etrafında boşluk YOK
full_name="Tommy Mir"         # boşluk varsa tırnak
echo $name
echo 'Benim adım $name'       # tek tırnak → genişletme yok
echo "Benim adım $name"       # çift tırnak → variable expansion
```

### Adlandırma kuralları
- Harf, rakam, `_` — **rakamla başlayamaz**
- Tire ve boşluk ❌
- Ortam değişkenleri: büyük harf konvansiyonu (`PATH`, `HOME`)

### Üç durum
| Durum | Anlam |
|---|---|
| `friend=Sara` | Tanımlı, değer var |
| `friend=` | Tanımlı, değer boş |
| `unset friend` | Tanımlı değil |

Değişken adları **case-sensitive**: `name`, `NAME`, `Name` farklıdır.

---

## env vs set

| Komut | Ne listeler |
|---|---|
| `env` | Ortam değişkenleri (environment variables) |
| `set` | Ortam + shell değişkenleri + fonksiyonlar (daha geniş) |

```bash
set | less
/hello                        # less içinde fonksiyon ara
```

### set -b — Notify Job Completion
Arka plan işi bitince anında bildirim:
```bash
set -b
sleep 5 &
# ~5 sn sonra: [1]+ Done sleep 5
set +b                        # kapat
```
Genel kural: `set -` seçeneği açar, `set +` kapatır.

## export ve fork
`fork()` — mevcut process'ten **child process** oluşturur. Parent ve child ayrı process'lerdir.

```bash
name=Tommy
bash                          # child shell
echo $name                    # boş — export edilmedi
exit
export name=Tommy             # veya: name=Tommy && export name
bash
echo $name                    # Tommy
exit
```

| | Shell variable | export (environment variable) |
|---|---|---|
| Child process | ❌ | ✅ |
| Örnek | `name=Tommy` | `export HTTP_PROXY=...` |

## source ve nokta operatörü (.)

```bash
echo 'my_conf="funny config"' > config.sh
chmod +x config.sh

./config.sh                   # child process → script bitince değişken kaybolur
echo $my_conf                 # boş

source config.sh              # mevcut shell'de çalışır
. config.sh                   # source ile aynı
echo $my_conf                 # funny config
```

| Kullanım | Amaç |
|---|---|
| `export` | Değişkeni child process'lere aktar |
| `source` / `.` | Script'i **mevcut shell**'de çalıştır |

`source ~/.bashrc` — alias, PS1, PATH güncellemelerini mevcut oturuma uygula.

---

## alias

```bash
alias                         # mevcut alias'lar
alias testing='ping 4.4.2.2'
alias testing                 # tek alias kontrol
```

Kalıcı yapmak → `~/.bashrc` içine ekle, sonra `source ~/.bashrc`.

Alias kişisel kolaylıktır; başka sunucuda olmayabilir — temel komutları bilmek gerekir.

---

## Fonksiyonlar

Alias'tan daha güçlü — birden fazla komut + mantık:

```bash
function funny_ls {
  ls
  echo "Bu funny_ls fonksiyonudur!"
}
# veya:
funny_ls() {
  ls
  echo "Bu funny_ls fonksiyonudur!"
}
funny_ls
```

`set | less` ile fonksiyon tanımını görebilirsin.

## PS1 — Prompt Özelleştirme

```bash
echo $PS1
PS1="hello "
PS1="\u@\h:\w\$ "             # user@host:dir$
```

| Kod | Anlamı |
|---|---|
| `\u` | Kullanıcı adı |
| `\h` | Hostname |
| `\w` | Mevcut dizin |
| `\t` | Saat |
| `\$` | `$` veya root için `#` |

Kalıcı → `~/.bashrc` + `source ~/.bashrc`.

## Üç Shell Türü

| Tür | Örnek | Login? | Interactive? |
|---|---|---|---|
| **Login shell** | SSH ile kullanıcı/parola girişi | ✅ | ✅ |
| **Interactive non-login** | Masaüstünde Terminal açma, `tmux` yeni pane | ❌ | ✅ |
| **Non-interactive** | `bash script.sh` | ❌ | ❌ |

Hangi config dosyalarının okunduğu buna bağlıdır.

### Login shell sırası
```
/etc/profile
  → /etc/profile.d/*
  → ~/.bash_profile   (varsa dur)
  → ~/.bash_login     (yoksa)
  → ~/.profile        (yoksa)
  → ~/.bashrc         (genelde .bash_profile içinden source edilir)
```

### Interactive non-login
```
/etc/bash.bashrc
  → ~/.bashrc
```

### Non-interactive
Varsayılan config **otomatik yüklenmez**. İsteğe bağlı:
```bash
export BASH_ENV="/tmp/config.sh"
bash script.sh                # önce BASH_ENV dosyasını okur
```

## /etc/skel ve .bash_logout

Yeni kullanıcı oluşturulunca `/etc/skel` içeriği home'a kopyalanır:
```bash
ls -a /etc/skel               # .bashrc, .profile, .bash_logout
```

`~/.bash_logout` — oturum kapanırken çalışır (örn. `clear`, logout zamanı logla).

Hidden dosyalar: `ls -a`

PATH'e dizin ekleme (`.bashrc`):
```bash
export PATH=$PATH:/home/firat/bin
source ~/.bashrc
```
