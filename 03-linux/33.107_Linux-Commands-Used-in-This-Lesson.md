# LPIC-107 — Linux Commands Used in This Lesson

## Komutlar ve yollar

| Komut / yol | Anlamı |
|---|---|
| `passwd` / `sudo passwd kullanıcı` | Kendi / başkasının şifresini değiştirir |
| `useradd` / `userdel` / `usermod` | Kullanıcı ekle / sil / değiştir |
| `adduser` | Debian/Ubuntu etkileşimli kullanıcı ekleme |
| `groupadd` / `groupdel` / `groupmod` | Grup ekle / sil / değiştir |
| `id` / `id kullanıcı` | UID, GID ve grup üyeliğini gösterir |
| `/etc/passwd` | Kullanıcı DB (`x` = şifre shadow’da) |
| `/etc/shadow` | Şifre hash + password aging (root) |
| `/etc/group` / `/etc/gshadow` | Grup listesi / grup şifreleri |
| `/etc/skel` | Yeni home şablon dizini |
| `getent passwd\|group\|hosts …` | Sistem DB’den kayıt sorgular |
| `chage` | Password aging görüntüle / ayarla |
| `/bin/false` / `/usr/sbin/nologin` | Login engelli shell |
| `crontab -l` / `crontab -e` | Kullanıcı cron listele / düzenle |
| `/etc/crontab` | Sistem geneli cron (kullanıcı alanı var) |
| `/etc/cron.d/` / `cron.daily` … | Ek / periyodik betik dizinleri |
| `/var/spool/cron/crontabs/` | Kullanıcı crontab dosyaları (Ubuntu) |
| `at` / `atq` / `atrm` | Tek seferlik iş / kuyruk / sil |
| `/etc/cron.allow` / `cron.deny` | cron beyaz / kara liste |
| `/etc/at.allow` / `at.deny` | at beyaz / kara liste |
| `systemctl list-timers` / `--all` | systemd timer listesi |
| `systemctl cat …timer` / `…service` | Unit içeriğini göster |
| `systemctl enable --now …timer` | Timer’ı etkinleştir ve başlat |
| `systemctl daemon-reload` | Unit değişikliklerini yükle |
| `journalctl -u servis` | Servis günlüklerini göster |
| `systemd-run --on-active=1m komut` | Geçici timer ile komut çalıştır |
| `date` / `date +%Y-%m-%d` | Tarih-saat / biçimli çıktı |
| `cal` / `cal -3` / `cal YIL` | Takvim |
| `timedatectl` | Saat dilimi, UTC, NTP durumu |
| `timedatectl set-timezone BÖLGE` | Sistem saat dilimini ayarla |
| `tzselect` | Saat dilimi seçim menüsü |
| `TZ=… date` / `unset TZ` | Geçici saat dilimi / sıfırla |
| `/etc/localtime` → `zoneinfo` | Sistem varsayılan timezone (symlink) |
| `locale` | LANG / LC_* değerlerini gösterir |
| `iconv -f … -t …` | Karakter kodlaması dönüştür |
| `dpkg-reconfigure locales` | Ubuntu locale yapılandırması |
| `localectl set-locale …` | Fedora locale ayarı |

## Seçenekler ve sözdizimi (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| `useradd` | `-d` / `-m` / `-s` / `-G` / `-c` | Home yolu / oluştur / shell / ek grup / açıklama |
| `usermod` | `-L` / `-U` | Hesabı kilitle / kilidi aç |
| `usermod` | `-aG grup kullanıcı` | Mevcut gruplara ekle (`-a` şart) |
| `userdel` | `-r` | Kullanıcı + home sil |
| `groupadd` / `groupmod` | `-g GID` | GID belirle / değiştir |
| `chage` | `-l` / `-M N` | Listele / max yaş |
| crontab | `dakika saat gün ay hafta komut` | Zamanlama alanları |
| crontab alanı | `*/5` / `1-5` / `*` | Her 5 dk / aralık / her değer |
| çıktı bastırma | `komut > /dev/null 2>&1` | stdout+stderr bastır |
| `at` | `now + 3 minutes` | 3 dakika sonra çalıştır |
| systemd timer | `OnCalendar=` / `OnBootSec=` | Takvim / monotonic |
| `locale` / ortam | `export LANG=C` / `LC_ALL=C` | Betik için tutarlı C locale |
| `iconv` | `-l` | Desteklenen kodlamaları listeler |
