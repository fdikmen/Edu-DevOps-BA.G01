## 107.1 — Kullanıcı ve Grup Yönetimi

### passwd
```bash
passwd                         # kendi şifreni değiştir (önce mevcut şifre sorulur)
sudo passwd fd                 # root: başkasının şifresi (mevcut şifre istenmez)
```
- Sıradan kullanıcı: zayıf/kısa/eski şifre reddedilebilir
- **Root** bu kurallara takılmaz (`123` kabul edilebilir)
- Normal kullanıcı ile `passwd` → mevcut şifre doğrulanır

### Komut ailesi
| Kullanıcı | Grup |
|---|---|
| `useradd` / `userdel` / `usermod` | `groupadd` / `groupdel` / `groupmod` |

`adduser` — Debian/Ubuntu'da etkileşimli (şifre, ad, oda…). Fedora'da genelde `useradd` ile aynı/yakın davranır.

### useradd bayrakları
| Bayrak | Anlam |
|---|---|
| `-d` | Home yolu |
| `-m` | Home dizinini oluştur |
| `-s` | Login shell (örn. `/bin/bash`) |
| `-G` | Ek gruplar |
| `-c` | Açıklama (GECOS) |

```bash
sudo useradd -d /tmp/dummy -m -s /bin/bash -c "yorum" newuser
sudo passwd newuser            # useradd şifre sormaz — ayrıca ver
```

```bash
sudo adduser super             # etkileşimli (Debian/Ubuntu)
id super
ls -la /home/
ls -a /etc/skel                # şablon: .bashrc, .profile, .bash_logout…
```
`/etc/skel` — skeleton: yeni home'a kopyalanan başlangıç dosyaları.

### usermod / userdel
```bash
sudo usermod -L super          # kilitle
sudo usermod -U super          # kilidi aç
sudo usermod -aG sudo super    # mevcut gruplara ekle (-a şart)
# usermod -G liste  → grupları tam listeye sıfırlar (eski üyeliği siler)

sudo userdel super
sudo userdel -r newuser        # -r → home'u da sil
```

### Gruplar
```bash
sudo groupadd fact1
sudo groupadd -g 1500 fact1
sudo groupmod -g 500 fact1
sudo groupdel fact1

sudo mkdir -p /tmp/proje
sudo chown :fact1 /tmp/proje
sudo usermod -aG fact1 fd      # üyelik sonraki login'de etkili olabilir
```

### UID / GID
```bash
id                             # kendi UID/GID/gruplar
id root                        # UID 0, GID 0
id fd                          # genelde 1000'den başlar
```

### Sistem dosyaları
| Dosya | İçerik |
|---|---|
| `/etc/passwd` | Kullanıcı DB: ad:`x`:UID:GID:GECOS:home:shell — **şifre burada değil** |
| `/etc/shadow` | Şifre hash + aging — normal kullanıcı okuyamaz |
| `/etc/group` | Gruplar: ad:şifre yer tutucu:GID:üyeler |
| `/etc/gshadow` | Grup şifreleri (nadiren kullanılır) |

```bash
head /etc/passwd
tail /etc/passwd
sudo tail /etc/shadow
ls -l /etc/passwd /etc/shadow  # passwd herkese okuma; shadow root
getent passwd fd
getent group fact1
```

**passwd alanları:** `kullanıcı:x:UID:GID:açıklama:home:shell`

Servis hesapları: shell çoğunlukla `/usr/sbin/nologin` veya `/bin/false` → oturum açılamaz.

**shadow şifre alanı:**
| Değer | Anlam |
|---|---|
| hash (`$6$…`) | Giriş yapılabilir |
| `!` | Kilitli (`usermod -L`) |
| `*` | Hiçbir şifre eşleşmez (imkânsız) |
| `!*` | Kilitli + imkânsız |

```bash
sudo useradd testuser          # Ubuntu: home yoksa; shadow'da `!`
sudo passwd testuser           # hash oluşur
sudo usermod -L testuser       # hash başına `!`
sudo usermod -U testuser       # `!` kalkar
```

### Password aging (`chage`)
shadow'da hash sonrası sayılar (ör. `20639:0:99999:7`):

| Alan | Anlam |
|---|---|
| Son değişim | 1970-01-01'den beri gün sayısı |
| Min gün | Tekrar değiştirme için bekleme (`0` = istediğin zaman) |
| Max gün | Geçerlilik süresi (`99999` ≈ pratikte sınırsız) |
| Uyarı | Sona ermeden kaç gün önce uyar |

```bash
sudo chage -l firat
sudo chage firat               # etkileşimli
sudo chage -M 30 firat         # max 30 gün
```
Elle `passwd`/`shadow` düzenlemek yerine: `usermod`, `passwd`, `chage`.

## 107.2 — Task Scheduling

| Araç | Ne zaman |
|---|---|
| **cron** / `crontab` | Periyodik (her gün, her saat…) |
| **at** | Tek seferlik |
| **systemd timer** | Modern alternatif (takvim veya olay) |
| **systemd-run** | Geçici / tek seferlik timer |

Ubuntu: `cron` genelde kurulu. Fedora: `cronie` + `systemctl enable --now crond`.

### crontab biçimi
```text
dakika  saat  gün  ay  haftanın_günü  komut
```

```bash
crontab -l
crontab -e
```

```cron
42 3 * * * /usr/local/bin/backup.sh          # her gün 03:42
0 18 1 * * program parametreler              # her ayın 1'i 18:00
*/5 * * * * komut                            # her 5 dakika
42 3 * * 1-5 /usr/local/bin/backup.sh        # iş günleri
# yorum satırı
0 8 * * * echo "Günaydın"
```

Haftanın günü: `0` ve `7` = Pazar; `1` = Pazartesi. Ayın günü 1–31; ay 1–12.

Çıktıyı bastırmak (mail birikmesin):
```cron
komut > /dev/null 2>&1
```

### Sistem geneli cron
| Yol | Rol |
|---|---|
| `/var/spool/cron/crontabs/` | Kullanıcı crontab'ları (Ubuntu) |
| `/etc/crontab` | Sistem geneli — **ek alan: kullanıcı adı** |
| `/etc/cron.d/` | Ek cron dosyaları |
| `/etc/cron.daily` / `.weekly` / `.monthly` / `.hourly` | Klasöre atılan çalıştırılabilir betikler |

```bash
cat /etc/crontab               # SHELL, PATH, MAILTO + run-parts satırları
ls /etc/cron.daily
chmod +x /etc/cron.daily/betik
```
Ubuntu: **anacron** ile daily/weekly/monthly makine kapalıyken kaçsa bile açılışta yakalanabilir. Dakikalık hassasiyet → kendi crontab satırı.

### at
```bash
sudo apt install at && sudo systemctl enable --now atd
at now + 3 minutes             # Ctrl+D ile bitir
at teatime                     # ~16:00
at tomorrow
atq                            # kuyruk
atrm 3                         # iş sil
```

### allow / deny
| Dosya | Etki |
|---|---|
| `/etc/cron.allow` / `/etc/at.allow` | Beyaz liste (varsa sadece listedekiler) |
| `/etc/cron.deny` / `/etc/at.deny` | Kara liste |

`allow` varsa genelde `deny` yok sayılır.

### systemd timer
```bash
systemctl list-timers
systemctl list-timers --all
ls /usr/lib/systemd/system/*.timer
systemctl cat plocate-updatedb.timer
systemctl cat plocate-updatedb.service
sudo systemctl enable --now plocate-updatedb.timer
sudo systemctl daemon-reload   # unit değişince
journalctl -u plocate-updatedb.service
```

| Tür | Örnek | Anlam |
|---|---|---|
| **OnCalendar** (realtime) | `daily`, `hourly`, `OnCalendar=Sat *-*-1..7 00:00:00` | Takvim zamanı |
| **Monotonic** | `OnBootSec=5min`, `OnActiveSec`, `OnUnitActiveSec` | Olaydan sonra süre |

Kısayollar: `hourly`, `daily`, `weekly`, `monthly`, `yearly`. Timer genelde aynı adlı `.service`'i tetikler.

### systemd-run (geçici)
```bash
systemd-run --on-active=1m touch /tmp/systemd-is-fun
```
`at` yerine modern alternatif.

## 107.3 — Localisation & Internationalisation

### Tarih / saat
```bash
date
date +%Y-%m-%d
date +%m%d_%H%M
touch backup_$(date +%m%d_%H%M)

cal
cal -3
cal 1998

timedatectl                    # timezone, local, UTC, NTP
sudo timedatectl set-timezone Europe/Istanbul
```

Ubuntu NTP: genelde `systemd-timesyncd`. Fedora: çoğu zaman `chronyd`.

### Saat dilimi
```bash
tzselect                       # menü → TZ önerir
TZ=Asia/Tokyo date
export TZ=Indian/Maldives      # .profile'a koyulabilir
unset TZ

ls -l /etc/localtime           # → /usr/share/zoneinfo/...
sudo timedatectl set-timezone US/Mountain
# eski yöntem: unlink + ln -s zoneinfo dosyasına (kopya değil — güncelleme için)
```

### Locale
```bash
locale                         # LANG, LC_* değerleri
# /etc/default/locale (Debian/Ubuntu) · /etc/locale.conf (Fedora)
sudo dpkg-reconfigure locales  # Ubuntu
# Fedora: sudo localectl set-locale LANG=en_US.UTF-8
```

| Değişken | Rol |
|---|---|
| `LANG` | Varsayılan dil/locale |
| `LC_ALL` | Tüm `LC_*` üzerine yazar |
| `LC_TIME` / `LC_PAPER` … | Tarih, kâğıt boyutu vb. |

**`LANG=C` / `LC_ALL=C`** — betiklerde öngörülebilir sıralama/çıktı (C ortamı; kültür farkı yok).

```bash
export LANG=C
```

### Karakter kodlaması
ASCII → ISO-8859 / WINDOWS-1254 → pratikte **UTF-8**.

```bash
iconv -f WINDOWS-1254 -t UTF-8 girdi.txt > cikti.txt
iconv -l                       # desteklenen kodlamalar
```
