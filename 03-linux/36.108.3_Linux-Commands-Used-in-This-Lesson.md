# LPIC-108.3 — Linux Commands Used in This Lesson

| Komut / Yol / Sözdizimi | Anlamı |
|---|---|
| `mail` / `mailx` / `mutt` | MUA: yazma, başlık, gönderme, okuma. MTA değildir |
| MTA | İletiyi kabul eder, yönlendirir, teslim eder; arka plan hizmetidir |
| Postfix / Exim / Sendmail | MTA örnekleri |
| `qmail` | Güvenlik ve hız odaklı MTA; Maildir ve süreç yalıtımı |
| TCP **25** | Sunucular arası SMTP |
| **587** | Kullanıcının posta sunucusuna gönderimi (submission) |
| `/var/mail/kullanıcı` | Yerel posta kutusu yolu |
| `/var/spool/mail/kullanıcı` | Yerel posta kutusu yolu |
| MX | Uzak alanın posta sunucusu kaydı |
| SMTP **250 OK** | Remote MTA iletiyi kabul etti; gelen kutusuna düştüğü anlamına gelmez |
| `MAIL FROM` | SMTP oturumundaki gönderen adresi; kimlik kanıtı değildir |
| SPF | Gönderen IP adresinin yetkisi |
| DKIM | Kriptografik imza |
| DMARC | SPF ve DKIM sonuçlarına göre politika ve raporlama |
| `sendmail.cf` | Sendmail yapılandırması; sözdizimi karmaşıktır |
| `m4` | Sendmail yapılandırmasını üretmek için makrolar |
| Maildir | Her ileti ayrı dosya olarak saklanır |
| `apt list --installed 2>/dev/null \| grep -E 'postfix\|exim\|sendmail\|qmail'` | Debian/Ubuntu: kurulu MTA paketleri |
| `rpm -qa \| grep -E 'postfix\|exim\|sendmail\|qmail'` | Fedora/RHEL/CentOS: kurulu MTA paketleri |
| `rpm -qa` | Kurulu paketleri listeler |
| `apt list --installed 2>/dev/null \| grep -E 'bsd-mailx\|mailutils'` | Debian/Ubuntu: posta istemci paketleri |
| `rpm -qa \| grep -E 'mailx'` | Fedora/RHEL/CentOS: mailx paketi |
| `bsd-mailx` | Terminalden gönderme ve okuma istemcisi |
| `mailutils` | E-posta komut ve araçları paketi |
| `command -v mail mailx mailq` | Üç komutun yolunu birlikte gösterir |
| `command -v mail` | `mail` varsa yolunu basar |
| `command -v mailx` | `mailx` varsa yolunu basar |
| `command -v mailq` | `mailq` varsa yolunu basar |
| `id && getent passwd "$USER"` | Mevcut kullanıcının kimliği ve passwd kaydı |
| `id` | UID, GID ve gruplar |
| `getent passwd "$USER"` | passwd veritabanındaki kayıt |
| `echo "Trial" \| mail -s "Test" "$USER"` | Kısa yerel ileti; gönderen ve alıcı aynı kullanıcı |
| `printf '%s\n' 'Bu, yerel posta kutusuna gönderilen bir denemedir.' \| mail -s 'Yerel posta denemesi' "$USER"` | `printf` ile yerel deneme |
| `-s` | Konu satırı |
| `"$USER"` | Alıcı: mevcut kullanıcı |
| `mail` | Posta kutusunu okuma modunda açar |
| `mail "$USER"` | Etkileşimli gönderim: alıcı, konu, gövde, Ctrl-D |
| `d` / `delete` | Seçili iletiyi siler |
| `r` / `reply` | Gönderene yanıt verir |
| `q` | Çıkar ve değişiklikleri kaydeder |
| `x` | Değişiklikleri kaydetmeden çıkar |
| `?` / `help` | Kullanılabilir komutları gösterir |
| Ctrl-D | İleti gövdesini bitirir (EOF) |
| CC + boş Enter | Başka kopya alıcısı eklemeden geçer |
| `man mail` / `man mailx` | Sürüme göre tuş davranışını doğrular |
| `printf '%s\n' 'Yedekleme scripti tamamlandı.' \| mail -s 'Yedekleme sonucu' "$USER"` | Tek satırlık betik bildirimi |
| `command <<EOF` … `EOF` | Heredoc; kapanış sözcüğü tek başına bir satırdadır |
| `mail -s 'Report' "$USER" <<'EOF'` | Çok satırlı gövde; tırnak genişletmeyi engeller |
| `<<'EOF'` | Gövde içindeki değişken ve komutlar olduğu gibi kalır |
| relay | İleti, hedef sunucudan önce başka bir posta sunucusu üzerinden gider |
| `/etc/aliases` | Alias tanımları |
| `postmaster: root` | postmaster adresini root’a yönlendirir |
| `webmaster: root` | webmaster adresini root’a yönlendirir |
| postmaster | Posta sistemi sorunları için standart adres |
| webmaster | Web sunucusundan sorumlu kişi için yaygın adres |
| `cat /etc/aliases` | Mevcut alias kayıtlarını gösterir |
| `sudoedit /etc/aliases` | Dosyayı yönetici yetkisiyle güvenli düzenler |
| `sudo newaliases` | Alias veritabanını günceller; MTA’yı yeniden yapılandırmaz |
| `postalias -q postmaster /etc/aliases` | postmaster alias’ının hedefini sorgular |
| `postalias -q webmaster /etc/aliases` | webmaster alias’ının hedefini sorgular |
| `MAILTO` | Cron çıktısının gideceği e-posta adresi |
| `MAILTO=""` | Boş tanımlı; hata çıktısı sessizce kaybolabilir |
| `printf '%s\n' 'Job output' \| mail -s 'Job output' "$USER"` | Cron açmadan yerel teslim denemesi |
| `/var/spool/postfix/` | Postfix kuyruk dizini |
| `/var/spool/mqueue/` | Sendmail uyumlu kuyruk dizini |
| `mailq` | Kuyruk: kimlik, boyut, zaman, gönderen, alıcı, bekleme nedeni |
| `postqueue -p` | Postfix kuyruğunu listeler |
| `telnet 127.0.0.1 25` | Yerel SMTP 25’e bağlanır; tek başına ileti göndermez |
| PTR | Ters DNS kaydı |
| STARTTLS | Sunucular arası SMTP bağlantısını şifreler |
| bounce | Teslim edilememe bildirimi; SMTP hata kodu ve açıklama taşır |
