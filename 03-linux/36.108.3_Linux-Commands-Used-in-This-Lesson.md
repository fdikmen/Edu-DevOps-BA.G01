# LPIC-108.3 — Linux Commands Used in This Lesson

## Komutlar ve yollar

| Komut / yol | Anlamı |
|---|---|
| `mail` / `mailx` / `mutt` | MUA: yazma, okuma, gönderme (MTA değildir) |
| `mail` | Posta kutusunu okuma modunda açar |
| `mail kullanıcı` | Etkileşimli gönderim (konu, gövde, Ctrl-D) |
| `mail -s "konu" kullanıcı` | Konu ile gönderim (gövde boru veya etkileşimli) |
| `mailq` | Posta kuyruğunu listeler |
| `postqueue -p` | Postfix kuyruğunu listeler |
| `command -v mail mailx mailq` | Bu komutların yolunu gösterir |
| `apt list --installed 2>/dev/null \| grep -E 'postfix\|exim\|sendmail\|qmail'` | Debian/Ubuntu: kurulu MTA paketleri |
| `rpm -qa \| grep -E 'postfix\|exim\|sendmail\|qmail'` | Fedora/RHEL/CentOS: kurulu MTA paketleri |
| `apt list --installed 2>/dev/null \| grep -E 'bsd-mailx\|mailutils'` | Debian/Ubuntu: posta istemci paketleri |
| `rpm -qa \| grep -E 'mailx'` | Fedora/RHEL/CentOS: mailx paketi |
| `/var/mail/kullanıcı` | Yerel posta kutusu yolu |
| `/var/spool/mail/kullanıcı` | Yerel posta kutusu yolu (alternatif) |
| `/etc/aliases` | Sistem alias tanımları |
| `sudoedit /etc/aliases` | Alias dosyasını yönetici olarak düzenler |
| `sudo newaliases` | Alias veritabanını günceller (MTA’yı yeniden yapılandırmaz) |
| `postalias -q ad /etc/aliases` | Alias hedefini sorgular |
| `/var/spool/postfix/` | Postfix kuyruk dizini |
| `/var/spool/mqueue/` | Sendmail uyumlu kuyruk dizini |
| `sendmail.cf` | Sendmail yapılandırması |
| `telnet 127.0.0.1 25` | Yerel SMTP dinleyicisine bağlanır (tek başına ileti göndermez) |

## Seçenekler, menü ve çıktı (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| `mail` | `-s` | Konu satırı |
| `mail` (okuma) | `d` / `delete` | Seçili iletiyi siler |
| `mail` (okuma) | `r` / `reply` | Gönderene yanıt |
| `mail` (okuma) | `q` | Kaydederek çıkar |
| `mail` (okuma) | `x` | Kaydetmeden çıkar |
| `mail` (okuma) | `?` / `help` | Komut listesi |
| `mail` (gönderim) | Ctrl-D | Gövdeyi bitirir (EOF) |
| `mail` (gönderim) | CC + boş Enter | Kopya alıcısı eklemeden geçer |
| `postqueue` | `-p` | Kuyruğu yazdır |
| SMTP | TCP **25** | Sunucular arası aktarım |
| SMTP | **587** | Submission (istemci → sunucu) |
| SMTP yanıtı | **250 OK** | Remote MTA kabul etti; gelen kutusuna düştüğü anlamına gelmez |
| SMTP oturumu | `MAIL FROM` | Gönderen adresi; kimlik kanıtı değildir |
| `/etc/aliases` | `postmaster: root` | postmaster → root |
| `/etc/aliases` | `webmaster: root` | webmaster → root |
| cron | `MAILTO` / `MAILTO=""` | Cron çıktısının gideceği adres; boşsa sessiz kayıp riski |
