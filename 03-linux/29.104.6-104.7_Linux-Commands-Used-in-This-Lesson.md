# LPIC-104.6 & 104.7 — Linux Commands Used in This Lesson

## Komutlar

| Komut | Anlamı |
|---|---|
| `ln kaynak hedef` | Hard link oluşturur (aynı inode) |
| `ln -s kaynak hedef` | Sembolik (soft) link oluşturur |
| `unlink dosya` / `rm dosya` | Link veya dosyayı siler |
| `ls -i` / `ls -li` | inode ile liste |
| `find . -type l` | Sembolik linkleri bulur |
| `which komut` | PATH’te çalışacak binary yolunu gösterir |
| `whereis komut` | Binary, man, kaynak konumlarını bulur |
| `whatis komut` | Komutun kısa man açıklamasını gösterir |
| `type komut` | Builtin mi, alias mı, binary mi gösterir |
| `echo $PATH` | PATH değişkenini gösterir |
| `export PATH=$PATH:/dizin` | PATH’e dizin ekler |
| `find …` | Dosya arama |
| `locate desen` | Veritabanından hızlı dosya arama |
| `updatedb` | locate veritabanını günceller |

## Seçenekler (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| `ln` | `-s` | Sembolik link |
| `which` | `-a` | PATH’teki tüm eşleşmeler |
| `find` | `-type l` | Yalnız symlink |
| `find` | `-user` / `-not -user` / `-nouser` | Sahip süzgeci |
| `find` | `-group` | Grup süzgeci |
| `find` | `-maxdepth N` | Derinlik sınırı |
| `find` | `-iname "*desen*"` | Büyük/küçük harf duyarsız ad |
