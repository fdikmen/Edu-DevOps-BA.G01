# LPIC-104.3 — Linux Commands Used in This Lesson

| Komut / Sözdizimi | Anlamı |
|---|---|
| `lsblk` | Blok cihazları ve mount point’leri listeler |
| `lsblk -o NAME,UUID` | İsim + UUID sütunları |
| `lsblk -O` | Tüm sütunları gösterir |
| `blkid` / `blkid /dev/sdb1` | Blok kimliği, UUID, tür, etiket |
| `fdisk /dev/sdb` | Bölüm oluştur/yönet (`n`, `w`) |
| `mkfs.ext4 /dev/sdb1` | Bölüm üzerinde ext4 oluştur |
| `mkdir /media/new_disk` | Mount point dizini |
| `mount` | Bağlı tüm dosya sistemlerini listeler |
| `mount /dev/sdb1 /media/new_disk` | Cihazı dizinine bağla |
| `mount -t ext4 …` | Türü açıkça belirt |
| `mount -o rw\|ro\|user\|noauto\|loop …` | Bağlama seçenekleri |
| `mount UUID=<uuid> /media/new_disk` | UUID ile bağla |
| `mount /dev/sdb1` | fstab varsa hedefi oradan al |
| `umount /dev/sdb1` | Cihaz adına göre ayır |
| `umount /media/new_disk` | Mount point’e göre ayır |
| `umount -f` | Zorla ayır (örn. erişilemeyen NFS) |
| `umount -l` | Lazy unmount — hemen hiyerarşiden ayır |
| `vi /etc/fstab` | Kalıcı bağlama tablosunu düzenle |
| `swapon` / `swapoff` | Swap (mount ile değil; hatırlatma) |
| `.mount` (systemd) | systemd mount birimi (farkındalık) |
