# LPIC-104.3 — Linux Commands Used in This Lesson

## Komutlar ve yollar

| Komut / yol | Anlamı |
|---|---|
| `lsblk` | Blok cihazları ve mount point’leri listeler |
| `blkid` / `blkid /dev/sdb1` | Blok kimliği, UUID, tür, etiket |
| `fdisk /dev/sdb` | Bölüm oluştur / yönet |
| `mkfs.ext4 /dev/sdb1` | Bölüm üzerinde ext4 oluştur |
| `mount` | Bağlı dosya sistemlerini listeler veya bağlar |
| `umount` | Dosya sistemini ayırır |
| `/etc/fstab` | Kalıcı bağlama tablosu |
| `swapon` / `swapoff` | Swap etkinleştir / kapat (mount değildir) |

## Seçenekler ve etkileşim (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| `lsblk` | `-o NAME,UUID` / `-O` | Sütun seçimi / tüm sütunlar |
| `fdisk` içinde | `n` / `w` | Yeni bölüm / yazıp çık |
| `mount` | `-t ext4` | Türü açıkça belirt |
| `mount` | `-o rw\|ro\|user\|noauto\|loop` | Bağlama seçenekleri |
| `mount` | `UUID=…` | UUID ile bağla |
| `umount` | `-f` / `-l` | Zorla / lazy unmount |
| systemd | `.mount` birimi | fstab alternatif farkındalığı |
