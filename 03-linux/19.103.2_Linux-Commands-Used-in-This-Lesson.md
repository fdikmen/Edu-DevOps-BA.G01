# LPIC-103.2 — Linux Commands Used in This Lesson

## Komutlar

| Komut | Anlamı |
|---|---|
| `cat` | Dosyaları birleştirip standart çıktıya yazdırır |
| `zcat` / `bzcat` / `xzcat` | Sıkıştırılmış dosyayı açmadan gösterir |
| `less` / `more` | Sayfa sayfa görüntüleme |
| `od` | Octal/hex/karakter dökümü |
| `split` | Dosyayı parçalara böler |
| `head` / `tail` | Dosyanın başı / sonu |
| `cut` | Alan / sütun seçer |
| `seq` | Ardışık sayı dizisi üretir |
| `\|` (pipe) | stdout → sonraki stdin (operatör; komut değil) |

## Seçenekler (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| `cat` | `-n` | Satır numarası |
| `od` | `-t c` / `-t a` / `-t x1` | Karakter / isim / hex byte |
| `od` | `-A d` | Ofsetleri ondalık göster |
| `split` | `-l N` / `-b N` / `-n N` | Satır / boyut / N parça |
| `split` | `-d` / `-a N` | Sayısal sonek / sonek uzunluğu |
| `head` | `-n N` / `-c N` | İlk N satır / N bayt |
| `tail` | `-f` | Canlı takip |
| `cut` | `-d'…' -fN` / `-b` / `-c` | Ayırıcı+alan / bayt / karakter |
