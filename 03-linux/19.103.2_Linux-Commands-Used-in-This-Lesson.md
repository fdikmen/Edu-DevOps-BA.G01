# LPIC-1032 — Linux Commands Used in This Lesson

| Komut | Anlamı |
|---|---|
| `cat` | Dosyaları birleştirip (concatenate) standart çıktıya yazdırır |
| `cat -n` | Çıktıya satır numarası ekler |
| `zcat` | gzip ile sıkıştırılmış dosyayı açmadan içeriğini gösterir |
| `bzcat` | bz2 ile sıkıştırılmış dosyayı açmadan içeriğini gösterir |
| `xzcat` | xz ile sıkıştırılmış dosyayı açmadan içeriğini gösterir |
| `less` | Dosyayı sayfa sayfa (interaktif) görüntüler |
| `more` | Eski (DOS kökenli) sayfalama komutu, less'in atası |
| `od` | Dosyayı octal/hex/karakter formatında döker (octal dump) |
| `od -t c` | İçeriği karakter olarak gösterir |
| `od -t a` | Karakterleri isimleriyle gösterir (sp, nl, ht) |
| `od -A d` | Ofsetleri ondalık (decimal) gösterir |
| `od -t x1` | İçeriği hexadecimal (1 byte) olarak gösterir |
| `split` | Bir dosyayı küçük parçalara böler |
| `split -l N` | N satırlık parçalara böler |
| `split -b N` | N boyutunda (örn. 10g) parçalara böler |
| `split -n N` | Dosyayı N parçaya böler |
| `split -d` | Parça isimlerinde harf yerine sayı kullanır |
| `split -a N` | Sonek uzunluğunu belirler |
| `head` | Dosyanın ilk satırlarını gösterir (varsayılan 10) |
| `head -n N` | İlk N satırı gösterir |
| `head -c N` | İlk N baytı gösterir |
| `tail` | Dosyanın son satırlarını gösterir (varsayılan 10) |
| `tail -f` | Dosyaya eklenen yeni satırları canlı takip eder |
| `cut -d -f` | Belirtilen ayırıcıya göre sütun (alan) seçer |
| `cut -b` | Bayt konumuna göre seçim yapar |
| `cut -c` | Karakter konumuna göre seçim yapar |
| `seq` | Ardışık sayı dizisi üretir |
| `pipe` (`\|`) | Bir komutun çıktısını diğerinin girdisine bağlar |
