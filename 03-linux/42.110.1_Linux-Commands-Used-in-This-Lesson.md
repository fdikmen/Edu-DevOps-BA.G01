# LPIC-110.1 — Linux Commands Used in This Lesson

Bu ders ayrıcalık, oturum, parola yaşı, SUID/SGID denetimi, süreç tavanı ve açık portu kapsar. `su` geleneksel olarak hedef parolasını sorar; PAM bunu değiştirebilir. `sudo` standart ayarda senin parolanı sorar. `nmap` yalnız izin verilen hedefe tutulur.

## Komutlar ve yollar

| Komut / yol | Anlamı |
|---|---|
| `whoami` | Etkin kullanıcı |
| `su` | Varsayılan hedef root. Dizin ve ortam çoğu zaman kalır |
| `su root` | Açıkça root. `su` ile aynı hedef; login ortamı yine tiresizde yüklenmez |
| `su -` | Root login shell. Ev `/root`, hedef ortamı yüklenir |
| `su newuser` | Kimlik değişir, çalışma dizini kalır |
| `su - newuser` | `newuser` login ortamı ve ev dizini |
| `exit` | İç içe kabukta bir seviye geri |
| `sudo useradd newuser` | Hesap açar. `-m` yoksa ev dizini oluşmaz |
| `sudo useradd -m newuser` | Hesap ve ev dizini |
| `sudo passwd newuser` | O hesabın parolasını koyar veya sıfırlar |
| `pwd` | `su` ile `su -` sonrası dizini karşılaştırmak için |
| `sudo ls /root` | Root ayrıcalığıyla liste |
| `touch myfile` | Kendi dizinininde dosya |
| `sudo touch /root/myfile` | Dosyayı root sahibi olarak oluşturur |
| `sudo -u newuser touch /tmp/myfile` | Sahip `newuser` olur |
| `sudo su` | Senin sudo yetkinle root kabuğu. Parola değişimi ayrı iştir |
| `sudo cat /etc/sudoers` | Yetki kurallarını okur. Yetkisiz hesap reddedilir |
| `sudo visudo` | Sözdizimini denetleyerek sudoers düzenler |
| `sudo usermod -aG sudo newuser` | Debian/Ubuntu sudo grubuna ekler. Bazı sistemlerde grup `wheel` |
| `who` | Şimdiki oturumlar. Kaynak çoğu zaman `/run/utmp` |
| `w` | Şimdiki oturum, boşta kalma, süreç/CPU |
| `last` | Geçmiş giriş, çıkış, süren oturum, reboot |
| `sudo last -f /var/log/btmp` | Başarısız girişler. Dosya her sistemde yoktur |
| `passwd` | Kendi parola; mevcut parola istenir |
| `sudo passwd firat` | Yönetici sıfırlar; eski parola sorulmaz |
| `passwd -S firat` | P/L/NP, son değişiklik, min, max, uyarı, pasif |
| `chage -l firat` | Yaşlandırma listesi |
| `sudo chage firat` | Etkileşimli yaşlandırma |
| `sudo chage -M 90 firat` | Maksimum parola yaşı 90 gün |
| `sudo chage -M -1 firat` | Maksimum yaşı kaldırır |
| `ls -l /usr/bin/passwd` | Sahip konumunda `s` ise SUID |
| `ls -l /usr/bin/ping` | Karşılaştırma; özel bit olmak zorunda değildir |
| `find /usr/bin -perm -u=s` | Bu ağaçta SUID biti açık dosyalar |
| `find / -type f -perm -4000 -ls 2>/dev/null` | Tüm sistemde SUID dosyaları |
| `find / -type f -perm -2000 -ls 2>/dev/null` | Tüm sistemde SGID dosyaları |
| `ulimit -a` | Soft limitler |
| `ulimit -Sa` | Soft limitler, açıkça |
| `ulimit -Ha` | Hard limitler |
| `ulimit -n 1024` | Açık dosya tanıtıcısı tavanı |
| `ulimit -t 1` | CPU süresi 1 saniye |
| `ulimit -v 1048576` | Sanal bellek, KB; ≈ 1 GiB |
| `sudo less /etc/security/limits.conf` | Kalıcı oturum tavanları |
| `netstat -na` | Sayısal adres ve port |
| `netstat -na \| grep LISTEN` | Dinleyen satırlar |
| `sudo netstat -lntup` | Dinleyen TCP/UDP, PID ve program |
| `ss -tuna` | TCP+UDP, sayısal, tüm soketler |
| `sudo ss -tulpen` | Dinleyen soket, PID, program |
| `sudo lsof -i -n -P` | Ağ dosyaları; isim çözmez, port sayısal |
| `sudo fuser -v 22/tcp` | 22/tcp sürecini gösterir |
| `man fuser` | Erişim harfleri |
| `nmap localhost` | Yerel makine; varsayılan yaklaşık 1000 TCP portu |
| `nmap example.org` | İzinli uzak hedef |
| `sudo nmap -O localhost` | İşletim sistemi tahmini |
| `nmap -p 53 target` | Tek TCP portu |
| `nmap -p 22,80,443 target` | Port listesi |
| `nmap -sn target` | Host keşfi; port taraması yok |
| `nmap -p- target` | TCP 1–65535 |
| `ip a` | Taramadan önce kendi adres ve arayüz |
| `nmap 192.168.70.2/24` | İzinli yerel ağ. Adres makineye göre değişir |
| `nmap -oN tarama-sonucu.txt 192.168.70.2/24` | Normal metin rapor |
| `/etc/sudoers` | Kim, nerede, kim olarak, hangi komut |
| `/etc/sudoers.d/` | Ek sudo kuralları |
| `/run/utmp` | Şimdiki oturum kaydı |
| `/var/log/btmp` | Başarısız girişler |
| `/etc/security/limits.conf` | Login kaynak tavanı |
| `/etc/shadow` | `passwd` SUID ile güncellenen parola kasası |

## Seçenekler, alanlar ve çıktı (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| `sudoers` | `%grup` | Kural kullanıcıya değil gruba |
| `sudoers` | `ALL=(ALL:ALL) ALL` | Her makine, her kullanıcı:grup, her komut |
| `sudoers` | `(ALL)` / `(ALL:ALL)` | Kim olarak / kim ve hangi grup olarak |
| `sudoers` | `NOPASSWD` | Belirtilen komutta parola sorma |
| `sudo` | parola önbelleği | Bir süre sonra tekrar sormayabilir |
| `passwd -S` | `P` / `L` / `NP` | Parola var / kilitli / yok |
| `passwd -S` | min max uyarı pasif | Gün cinsinden yaşlandırma |
| `chage -M` | `-1` | Bu seçenekte maksimum yaş yok |
| `ls -l` | `-rwsr-xr-x` | SUID ve çalıştırma |
| `ls -l` | `-rwxr-sr-x` | SGID |
| `ls -l` | büyük `S` | Bit açık, çalıştırma kapalı |
| `find -perm` | baştaki `-` | Bit yeter. Tiresiz tam eşleşme |
| `find` | `-4000` / `-2000` | SUID / SGID |
| `ulimit` | soft / hard | O anki tavan / yükseltilebilecek tavan |
| `ulimit -t` | saniye | CPU süresi, duvar saati değil |
| `limits.conf` | domain type item value | Kim, soft/hard, kaynak, sayı |
| `limits.conf` | `@grup` | Grup alanı |
| `limits.conf` | `-` | Hem soft hem hard |
| `limits.conf` | `pam_limits` | Yeni login’de uygulanır |
| dinleme | `127.0.0.1` | Yalnız loopback |
| dinleme | `0.0.0.0` | Tüm IPv4 arayüzleri |
| soket | `LISTEN` / `ESTABLISHED` | Kabul ediyor / kurulmuş bağlantı |
| `fuser` | `f` `F` `c` `e` | Açık dosya, yazma, çalışma dizini, program |
| `ss` | `-t -u -n -a -l -p` | TCP, UDP, sayısal, hepsi, dinleyen, süreç |
| `nmap` | `open` | Portta kabul eden hizmet var |
| `nmap` | varsayılan | Yaklaşık en yaygın 1000 TCP portu |
| `nmap -O` | OS tahmini | Garanti yok, çoğu zaman root ister |
| `nmap -oN` | metin dosyası | Çalışılan dizine yazar |
| port | 22 / 80 / 443 | SSH / HTTP / HTTPS ile sık eşleşir |

## Örnek akış

Kimlik, sonra tek komut, sonra oturum:

```text
whoami
pwd
su
pwd
exit
sudo -u newuser touch /tmp/myfile
who
w
last
```

Parola durumu ve SUID denetimi:

```text
passwd -S firat
chage -l firat
ls -l /usr/bin/passwd
find /usr/bin -perm -u=s
```

Bu makinede kim dinliyor:

```text
ss -tuna
sudo ss -tulpen
sudo fuser -v 22/tcp
```
