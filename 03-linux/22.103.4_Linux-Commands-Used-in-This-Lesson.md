# LPIC-103.4 / 103.5 — Linux Commands Used in This Lesson

## Komutlar ve yönlendirme

| Komut / sözdizimi | Anlamı |
|---|---|
| `>` / `1>` / `>>` / `1>>` | stdout yaz / sonuna ekle |
| `2>` / `2>>` | stderr yaz / sonuna ekle |
| `2>&1` / `&>` / `&>>` | stderr→stdout / ikisini birlikte |
| `<` | stdin dosyadan |
| `<< SON` / `<< EOF` | Here document |
| `/dev/null` | Yazılanı yok sayan cihaz |
| `\|` (pipe) | stdout → sonraki komutun stdin’i |
| `cut` | Alan / sütun seçer |
| `sed` | Akış düzenleme (ör. `sed 's/ //g'`) |
| `sort` / `uniq` | Sırala / ardışık tekilleştir |
| `wc -l` | Satır say |
| `xargs` | Stdin’i argüman olarak verir |
| `tee` | Hem ekrana hem dosyaya yazar |
| `jobs` | Shell işlerini listeler |
| `fg` / `bg` | İşi ön plana / arka plana al |
| `komut &` | Arka planda başlat |
| `nohup komut &` | SIGHUP yok sayarak arka planda çalıştır |
| `nohup.out` | nohup varsayılan çıktı dosyası |
| `tail -f` | Dosyaya eklenen satırları canlı takip eder |
| `kill PID` | TERM (15) sinyali |
| `killall isim` | Ada göre sinyal |
| `pkill desen` | Regex ile sinyal |

## Seçenekler ve tuşlar (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| `cut` | `-d'…' -fN` | Ayırıcı ve alan numarası |
| `sort` | `-nr` | Sayısal ters sıralama |
| `uniq` | `-c` | Tekrar sayarak tekilleştir |
| `xargs` | `-I {}` / `-n N` | Yer tutucu / N argüman |
| `tee` | `-a` | Dosya sonuna ekle |
| `jobs` | `-l` | PID ile listele |
| `fg` / `bg` | `%N` | İş numarası |
| `kill` | `-9` / `-1` | KILL / HUP |
| klavye | `Ctrl+C` | Ön plan process’i sonlandır (INT) |
| klavye | `Ctrl+Z` | Process’i durdur (STOP) |
