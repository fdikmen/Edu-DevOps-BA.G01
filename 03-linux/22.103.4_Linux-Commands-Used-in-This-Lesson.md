# LPIC-103.4 / 103.5 — Linux Commands Used in This Lesson

| Komut / Sözdizimi | Anlamı |
|---|---|
| `>` / `1>` | stdout'u dosyaya yazar (üzerine yazar) |
| `>>` / `1>>` | stdout'u dosyanın sonuna ekler (append) |
| `2>` / `2>>` | stderr'i dosyaya yazar / sonuna ekler |
| `2>&1` | stderr'i stdout'un gittiği yere yönlendirir |
| `&>` / `&>>` | stdout+stderr birlikte yaz / sonuna ekle |
| `<` | stdin'i dosyadan alır |
| `<< SON` / `<< EOF` | Here doc — çok satırlı girdi bloğu |
| `/dev/null` | Yazılan her şeyin yok sayıldığı cihaz |
| `\|` (pipe) | Bir komutun stdout'unu diğerinin stdin'ine bağlar |
| `cut -d -f` | Ayırıcıya göre alan (sütun) seçer |
| `sed 's/ //g'` | Boşlukları global siler (örnek) |
| `sort` / `sort -nr` | Sıralar / sayısal ters sıralar |
| `uniq -c` | Ardışık tekrarları sayarak tekilleştirir |
| `wc -l` | Satır sayar |
| `xargs` | Stdin değerlerini komuta argüman olarak verir |
| `xargs -i` | `{}` yer tutucusu ile argüman konumunu seçer |
| `xargs -n N` | Her çalıştırmada N argüman kullanır |
| `tee` | Çıktıyı hem ekrana hem dosyaya yazar |
| `tee -a` | Dosyanın sonuna ekler (append) |
| `Ctrl+C` | Ön plandaki süreci sonlandırır |
| `Ctrl+Z` | Süreci durdurur / askıya alır (Stopped) |
| `jobs` | Mevcut shell işlerini listeler |
| `jobs -l` | İşlerle birlikte PID gösterir |
| `fg` / `fg %N` | İşi ön plana getirir |
| `bg` / `bg %N` | Durdurulmuş işi arka planda devam ettirir |
| `komut &` | Komutu doğrudan arka planda başlatır |
| `nohup komut &` | SIGHUP'ı yok sayarak arka planda çalıştırır |
| `nohup.out` | nohup varsayılan çıktı dosyası |
| `tail -f` | Dosyaya eklenen satırları canlı takip eder |
| `kill PID` | TERM (15) sinyali gönderir |
| `kill -9 PID` | KILL — zorla sonlandırır |
| `kill -1 PID` | HUP sinyali gönderir |
| `sudo kill` | Başka kullanıcıya ait sürece sinyal (root) |
| `killall isim` | Tam isim eşleşmesiyle sinyal gönderir |
| `pkill desen` | Regex ile isme göre sinyal gönderir |
