# LPIC-109.3 — Linux Commands Used in This Lesson

Bu ders hostun kendi tarafından kanıt toplar: adres, geçit, uzak IP, ad, rota, yol, dinleyen port ve hat üzerindeki paket. `hostname` 109.2’de kaldı. Canlı `ip route` değişiklikleri reboot’ta kaybolur.

## Rota deneyi

Geçit örneği `10.0.2.2`. Hosttaki değer `ip route` içindeki `default via` satırıdır.

```text
sudo ip route delete default
ping 4.2.2.4
sudo ip route add 4.2.2.4 via 10.0.2.2
sudo ip route add default via 10.0.2.2
```

İlk `ping`, yol kalmadığı için `Network is unreachable` der. Ortadaki satır yalnız `4.2.2.4`’ü açar. Son satır bilinmeyen her hedefi yine geçide gönderir.
