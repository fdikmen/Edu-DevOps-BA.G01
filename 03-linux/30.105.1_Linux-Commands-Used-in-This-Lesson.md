# LPIC-105.1 — Linux Commands Used in This Lesson

## Komutlar

| Komut | Anlamı |
|---|---|
| `isim=deger` | Shell değişkeni tanımlar (`=` etrafında boşluk yok) |
| `echo $isim` | Değişken değerini gösterir |
| `env` | Ortam değişkenlerini listeler |
| `set` | Shell + ortam değişkenleri ve fonksiyonları listeler |
| `unset isim` | Değişkeni kaldırır |
| `export isim=deger` | Değişkeni child process’lere aktarır |
| `bash` | Yeni child Bash shell başlatır |
| `exit` | Mevcut shell’den çıkar |
| `./script.sh` | Script’i child process’te çalıştırır |
| `source script.sh` / `. script.sh` | Script’i mevcut shell’de çalıştırır |
| `chmod +x script.sh` | Script’e çalıştırma izni verir |
| `alias` / `alias ad='komut'` | Alias listele / tanımla |
| `function ad { … }` / `ad() { … }` | Shell fonksiyonu tanımlar |
| `PS1="…"` | Prompt metnini değiştirir |
| `source ~/.bashrc` | .bashrc’yi mevcut shell’e yükler |
| `export BASH_ENV=/path` | Non-interactive shell config dosyası |

## Seçenekler ve ilgili (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| `set` | `-b` / `+b` | Arka plan bitince bildir / kapat |
| `set` çıktısı | `\| less` | Uzun çıktıyı sayfala (yardımcı kullanım) |
| ortam | `echo $PS1` / `echo $BASH_ENV` | Prompt / BASH_ENV değerini oku |
| `.bashrc` örnekleri | `ls -a` / `ls /etc/profile.d/` | Hidden liste / profile.d içeriği |
| `set -b` demosu | `sleep N &` | Arka plan işi |
