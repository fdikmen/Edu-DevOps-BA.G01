# LPIC-105.1 — Linux Commands Used in This Lesson

| Komut / Sözdizimi | Anlamı |
|---|---|
| `isim=deger` | Shell değişkeni tanımlar (`=` etrafında boşluk yok) |
| `echo $isim` | Değişken değerini gösterir |
| `env` | Ortam değişkenlerini listeler |
| `set` | Shell + ortam değişkenleri ve fonksiyonları listeler |
| `set \| less` | set çıktısını sayfa sayfa inceler |
| `set -b` | Arka plan işi bitince anında bildirim (notify) |
| `set +b` | notify özelliğini kapatır |
| `unset isim` | Değişkeni tamamen kaldırır |
| `export isim=deger` | Değişkeni child process'lere aktarır |
| `export isim` | Önceden tanımlı değişkeni export eder |
| `bash` | Yeni child Bash shell başlatır |
| `exit` | Mevcut shell'den çıkar |
| `./script.sh` | Script'i ayrı child process'te çalıştırır |
| `source script.sh` | Script'i mevcut shell'de çalıştırır |
| `. script.sh` | `source` ile aynı |
| `chmod +x script.sh` | Script'e çalıştırma izni verir |
| `alias` | Tanımlı alias'ları listeler |
| `alias ad='komut'` | Yeni alias tanımlar |
| `function ad { … }` / `ad() { … }` | Shell fonksiyonu tanımlar |
| `echo $PS1` | Mevcut prompt yapılandırmasını gösterir |
| `PS1="…"` | Prompt metnini değiştirir |
| `source ~/.bashrc` | .bashrc ayarlarını mevcut shell'e yükler |
| `ls -a` | Hidden dosyalar dahil listeler |
| `ls /etc/profile.d/` | Sistem geneli profile parçalarını listeler |
| `echo $BASH_ENV` | Non-interactive shell startup dosyasını gösterir |
| `export BASH_ENV=/path` | Non-interactive shell için config dosyası |
| `sleep N &` | Arka planda N saniye bekleyen iş (set -b demo) |
| `clear` | Ekranı temizler (.bash_logout örneği) |
