# LPIC-109.1 — Linux Commands Used in This Lesson

Bu ders ağırlıkla adres, maske ve protokol bilgisidir. Aşağıdakiler notlardaki pratik bakışlardır: bağlantı denemesi, servis–port listesi, ikili dönüşüm. Adresi kalıcı yazmak sonraki derstir.

## Komutlar ve yollar

| Komut / yol | Anlamı |
|---|---|
| `ping 192.168.1.10` | ICMP Echo Request gönderir, cevap süresini gösterir |
| `ping -c 4 192.168.1.10` | Dört paket sonra durur |
| `ping -c 4 8.8.8.8` | Public bir adrese ulaşımı dener |
| `/etc/services` | Servis adı, port ve protokol listesi |
| `grep -E '^snmp[[:space:]]' /etc/services` | SNMP satırını gösterir (`161/tcp` ve `161/udp`) |
| `grep -E 'www([[:space:]]|$)' /etc/services` | `http` satırındaki `www` takma adını gösterir (`80`) |
| `tcpdump -n port 80` | 80 numaralı porta ait trafiği sayı olarak gösterir |
| `tcpdump port www` | Aynı işi servis adıyla yapar; `www` = `80/tcp` |

## Seçenekler ve çıktı (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| `ping` | `-c` | Gönderilecek paket sayısı |
| `ping` | `time=10ms` | Gidiş-dönüş yaklaşık 10 milisaniye |
| `ping` | cevap yok | Süre doldu; host kapalı, yol bozuk veya ICMP engelli olabilir |
| `/etc/services` | `snmp 161/tcp` ve `161/udp` | SNMP’nin beklenen portu |
| `/etc/services` | `http 80/tcp` | HTTP kaydı; takma ad `www` |
| `tcpdump` | `port www` | Port numarası yerine `/etc/services` adı |
| `tcpdump` | `-n` | Adres ve portu sayı olarak bırakır |

## Aynı ağ mı — elde hesap

`192.168.1.100/24` için ağ ve broadcast. Host bitleri (son oktet) 0 veya 255 yapılır.

```text
IP         192.168.1.100
Netmask    255.255.255.0    (/24)
Network    192.168.1.0
Broadcast  192.168.1.255
```

`10.0.0.1/24` ile karşılaştırma:

```text
10.0.0.12   aynı ağ     (10.0.0 sabit)
10.0.1.12   farklı ağ   (üçüncü oktet 0 → 1)
```

## Oktet dönüşümü

Ağırlıklar soldan sağa `128 64 32 16 8 4 2 1`. `1` olanlar toplanır.

```text
10010011 = 128 + 16 + 2 + 1 = 147
147      = 10010011
```

Kalan ≥ ağırlık ise bit `1` ve ağırlık düşülür; kalan < ağırlık ise bit `0`.
