# LPIC-103.6 — Linux Commands Used in This Lesson

| Komut / Sözdizimi | Anlamı |
|---|---|
| `nice` | Varsayılan niceness değerini gösterir (genelde 0) |
| `nice komut` | Komutu niceness 10 ile başlatır |
| `nice -n N komut` | Komutu belirtilen niceness ile başlatır |
| `renice -n N PID` | Çalışan sürecin niceness değerini değiştirir |
| `ps -l` | Long format — NI (niceness) sütununu gösterir |
| `ps` / `top` | Process listesi; top’ta NI sütunu ve canlı izleme |
| `r` (top içinde) | Seçilen PID için renice başlatır |
| `pgrep isim` | İsme göre PID bulur |
| `pgrep … \| xargs renice -n N` | Eşleşen tüm process'lere toplu renice |
| `man ps` | Process durum kodları (STAT) için kılavuz |
| `STAT: R` | Running |
| `STAT: S` | Interruptible sleep |
| `STAT: T` / `t` | Job control / debugger ile durdurulmuş |
| `STAT: D` | Uninterruptible sleep (I/O) |
| `STAT: Z` | Zombie |
| `STAT: I` / `W` / `X` | Idle thread / paging / dead |
