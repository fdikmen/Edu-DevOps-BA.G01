# LPIC-103.6 — Linux Commands Used in This Lesson

## Komutlar

| Komut | Anlamı |
|---|---|
| `nice` | Varsayılan niceness’i gösterir (genelde 0) |
| `nice komut` | Komutu niceness 10 ile başlatır |
| `nice -n N komut` | Belirtilen niceness ile başlatır |
| `renice -n N PID` | Çalışan process’in niceness’ini değiştirir |
| `ps -l` | Long format — NI sütunu |
| `ps` / `top` | Process listesi; top’ta NI ve canlı izleme |
| `pgrep isim` | İsme göre PID bulur |
| `pgrep … \| xargs renice -n N` | Eşleşen process’lere toplu renice |
| `man ps` | Process durum kodları (STAT) kılavuzu |

## Seçenekler, tuşlar ve çıktı (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| `nice` / `renice` | `-n N` | Niceness değeri |
| `top` içinde | `r` | Seçilen PID için renice |
| `ps` STAT | `R` | Running |
| `ps` STAT | `S` | Interruptible sleep |
| `ps` STAT | `T` / `t` | Job control / debugger ile durdurulmuş |
| `ps` STAT | `D` | Uninterruptible sleep (I/O) |
| `ps` STAT | `Z` | Zombie |
| `ps` STAT | `I` / `W` / `X` | Idle / paging / dead |
