# LPIC-106 — Linux Commands Used in This Lesson

| Komut / Yol / Kavram | Anlamı |
|---|---|
| `DISPLAY` | X Client'ın bağlanacağı X Server'ı belirten ortam değişkeni |
| `echo $DISPLAY` | Mevcut DISPLAY değerini gösterir |
| `xhost` | X Server erişim listesini yönetir (hangi istemciler bağlanabilir) |
| `xauth` | Authentication cookie ile X Server erişimini doğrular |
| `/etc/X11/xorg.conf` | Xorg ana yapılandırma dosyası (çoğu modern sistemde opsiyonel) |
| `/etc/X11/xorg.conf.d/` | Parça Xorg yapılandırma dizini |
| `~/.xsession-errors` | Kullanıcı grafik oturumu hata ve mesaj günlüğü |
| `Xorg` | Linux'ta yaygın X11 X Server implementasyonu |
| `GDM` | GNOME Display Manager — login + session (GNOME ile yaygın) |
| `SDDM` | Simple Desktop Display Manager — KDE Plasma ile yaygın |
| `LightDM` | Hafif Display Manager — çeşitli DE'lerle kullanılabilir |
| `XDMCP` | X11 Display Manager üzerinden uzak grafik oturumu protokolü |
| `VNC` | Uzak ekranı görüntüleme ve kontrol |
| `SPICE` | Özellikle VM grafik konsol erişimi (virtualization) |
| `RDP` | Remote Desktop Protocol |
| `TCP 3389` | RDP ile yaygın varsayılan port |
| `xrdp` | Linux'ta RDP oturumu sunan yazılım örneği |
| `Orca` | Linux Screen Reader (TTS tabanlı) |
| `emacspeak` | Emacs tabanlı Screen Reader örneği |
