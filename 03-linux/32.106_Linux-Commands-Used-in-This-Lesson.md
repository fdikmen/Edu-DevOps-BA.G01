# LPIC-106 — Linux Commands Used in This Lesson

## Komutlar ve yollar

| Komut / yol | Anlamı |
|---|---|
| `echo $DISPLAY` | Mevcut DISPLAY değerini gösterir |
| `xhost` | X Server erişim listesini yönetir |
| `xauth` | Authentication cookie ile X erişimini doğrular |
| `/etc/X11/xorg.conf` | Xorg ana yapılandırma (çoğu sistemde opsiyonel) |
| `/etc/X11/xorg.conf.d/` | Parça Xorg yapılandırma dizini |
| `~/.xsession-errors` | Grafik oturumu hata günlüğü |
| `xrdp` | Linux’ta RDP oturumu sunan yazılım örneği |

## Kavramlar ve protokoller (komut değildir)

| Öğe | Anlamı |
|---|---|
| `DISPLAY` | X Client’ın bağlanacağı X Server ortam değişkeni |
| `Xorg` | Yaygın X11 X Server implementasyonu |
| GDM / SDDM / LightDM | Display Manager örnekleri |
| XDMCP / VNC / SPICE / RDP | Uzak grafik erişim protokolleri |
| TCP **3389** | RDP ile yaygın varsayılan port |
| Orca / emacspeak | Screen Reader örnekleri |
