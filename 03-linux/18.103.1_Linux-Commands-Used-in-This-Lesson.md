# Derste Geçen Linux Komutları ve Anlamları

## Komutlar

| Komut / sözdizimi | Açıklama |
|---|---|
| `echo $değişken` | Ortam / shell değişkeninin değerini yazar |
| `değişken=değer` | Shell değişkeni tanımlar (`=` etrafında boşluk yok) |
| `unset değişken` | Değişkeni kaldırır |
| `env` | Ortam değişkenlerini listeler |
| `export değişken=değer` | Değişkeni child process’lere aktarır |
| `bash` | Yeni child bash oturumu başlatır |
| `echo $$` | Mevcut bash PID’sini gösterir |
| `set` | Shell + ortam değişkenleri ve ayarları listeler |
| `PATH=$PATH:/dizin` | PATH’e dizin ekler |
| `which komut` | PATH’te çalışacak kopyayı gösterir |
| `whereis komut` | Binary / man konumlarını listeler |
| `whatis komut` | Kısa komut açıklaması |
| `./program` / `/tam/yol/program` | Göreli / mutlak yolla çalıştırır |
| `cat ~/.bash_history` | History dosyasını okur |
| `history` | Bellekteki komut geçmişini listeler |
| `exit` | Shell oturumundan çıkar |

## Seçenekler, tuşlar ve history sözdizimi (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| history | `!numara` / `!!` / `!kelime` | Numaralı / son / kelimeyle eşleşen komutu tekrarla |
| klavye | `Ctrl+R` / `Ctrl+O` | Reverse-i-search / onayla |
| klavye | `↑` | Önceki komut |
| klavye | `Ctrl+D` | `exit` ile aynı (EOF) |
| history boyutu | `HISTSIZE=0` | Bu oturumda history tutmayı kapat |

## Öne çıkan ortam değişkenleri

| Değişken | Anlamı |
|---|---|
| `SHELL` | Kullanılan shell |
| `HOSTNAME` | Makine adı |
| `EDITOR` | Varsayılan editör |
| `PWD` / `OLDPWD` | Bulunulan / önceki dizin |
| `USER` / `LOGNAME` | Kullanıcı adı |
| `PATH` | Komut arama yolları |
| `HISTFILE` | History dosyası yolu |
| `PS1` | Prompt tanımı |
| `HISTSIZE` | Bellekte tutulacak history sayısı |
