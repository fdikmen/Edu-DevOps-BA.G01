# LPIC-103.8 — Temel Dosya Düzenleme (Vim)

## Konu
Ağırlık **3**. VI / **Vim** (*VI improved*) ile temel dosya düzenleme: modlar, gezinme, ekleme/silme/kopyalama, arama ve çıkış.

**Hedef:** Oturum sonunda Vim ile metin ekleyip silebilmek, kopyalayabilmek, arayabilmek — ve çoğu kişinin bilmediği şeyi, yani **Vim’den çıkmayı** bilmek.

**Senaryo:** SSH ile uzak sunucuya bağlandın; süslü GUI editör yok. Ortada VI/Vim var — dosyayı düzenlemen gerekiyor.

---

## Neden Vim?
- Unix/Linux sistemlerinin büyük kısmında en azından **VI** veya **Vim** bulunur (*omnipresence*).
- Minimal ortamda, 60 tuşluk klavyede bile temel VI komutları yeter.
- `vi` çağırınca çoğu distro (örn. Ubuntu) aslında **Vim** çalıştırır:

```bash
which vi
which vim
vi          # argümansız → Vim karşılama ekranı (Bram Moolenaar ve katkıda bulunanlar)
```

Bu oturumda eklentiler değil; **temeller** var.

---

## İki Ana Mod: Insert ve Normal

Vim’de birçok mod vardır (normal, insert, visual, command-line/Ex, replace, select…). Bu derste odak: **insert** ve **normal**.

| Geçiş | Sonuç |
|---|---|
| `i` | İmlecin **öncesinden** insert mode |
| `I` (Shift+I) | Satır **başına** gidip insert mode |
| `Esc` | Insert → **normal** mode (`-- INSERT --` kaybolur) |

- **Insert:** Yazılan her şey belgeye anında yansır; `Enter` yeni satır.
- **Normal:** Silme, kopyalama, arama, gezinme; ok tuşları bazı terminallerde çalışmayabilir → emin olmak için `Esc`, sonra `h`/`j`/`k`/`l`.

---

## Gezinme (Normal Mode)

### Karakter: `h` `j` `k` `l`
| Tuş | Yön |
|---|---|
| `h` | Sol |
| `j` | Aşağı |
| `k` | Yukarı |
| `l` | Sağ |

Sayı ile tekrar: `4l` → 4 sağa; `4j` → 4 aşağı.

### Kelime / sayfa: `w` `b` `e` · `Ctrl+F` `Ctrl+B`
| Komut | Anlamı |
|---|---|
| `w` | Sonraki kelimenin **başı** |
| `b` | Önceki kelimenin **başı** |
| `e` | Kelimenin **sonu** |
| `5w` / `2e` | Sayı + hareket = hızlı atlama |
| `Ctrl+F` | Sayfa aşağı (forward) |
| `Ctrl+B` | Sayfa yukarı (back) |

### Satır / dosya / ekran: `G` `gg` `H` `L`
| Komut | Anlamı |
|---|---|
| `G` | Dosya **sonu** |
| `gg` / `1G` | Dosya **başı** |
| `2G` / `100G` | 2. / 100. satır |
| `H` | Ekranın **üstü** (*high*) |
| `L` | Ekranın **altı** (*low*) |
| `5H` / `4H` | Ekranın üstünden N. satır |

---

## Metin Düzenleme

### Ekleme: `i` · `a` · `o` · `O`
| Komut | Anlamı |
|---|---|
| `i` | İmlecin **öncesine** insert |
| `a` | İmlecin **sağına** append (satır sonuna nokta eklemek için kritik) |
| `o` | Altında yeni satır + insert |
| `O` | Üstünde yeni satır + insert |

### Değiştir / sil: `r` · `x` · `X` · `d`
| Komut | Anlamı |
|---|---|
| `r` + karakter | Tek karakteri **replace** (şık yol) |
| `x` | İmlecin üzerindeki karakteri sil |
| `X` | Soldaki karakteri sil (Backspace benzeri) |
| `3x` | Üç karakter birden |
| `dw` / `3dw` | Kelime / 3 kelime sil |
| `dd` / `2dd` | Satır / 2 satır sil |

`d` hareket komutlarıyla birleşir (*delete + motion*).

### Yapıştır / kopyala: `p` `P` · `y` `yy`
| Komut | Anlamı |
|---|---|
| `p` | İmlecin **sonrasına** yapıştır |
| `P` | İmlecin **öncesine** yapıştır |
| `y` + hareket | Yank (silmeden kopyala) |
| `yy` | Satırı kopyala |

**Sık kullanılan hile:** `xp` — iki karakteri yer değiştir (yanlış yazılan `21` → `12` gibi).

---

## Arama

| Komut | Anlamı |
|---|---|
| `/kelime` + Enter | İleri doğru ara |
| `?kelime` + Enter | Geri doğru ara |
| `n` | Sonraki eşleşme (arama yönüne göre) |
| `N` | Önceki eşleşme (ters yön) |

Belge sonuna gelince Vim döngüsel devam eder (*search hit BOTTOM, continuing at TOP* benzeri mesaj).

Pratik: `/me` → sil → `you` yaz → Escape.

---

## Çıkış ve Dosya İşlemleri (Command / Ex Mode)

Normal mode’da `:` ile command-line (Ex) komutları:

| Komut | Anlamı |
|---|---|
| `:q` | Çık (kaydedilmemiş değişiklik varsa reddeder) |
| `:q!` | Kaydetmeden **zorla** çık (`!` = “biliyorum ne yaptığımı”) |
| `:w` | Kaydet (write) |
| `:w /tmp/dosya` | Farklı konuma yaz |
| `:w!` | Üzerine yazmayı zorla |
| `:wq` | Yaz ve çık |
| `ZZ` | Yaz ve çık (kısa yol; `:` yok) |
| `:e!` | Diskteki orijinal hâli yeniden oku (değişiklikleri at) |
| `:! ls` | Vim içinden shell komutu çalıştır |

## Yardım, Diğer Editörler, EDITOR

### Yardım
- `:help` veya `F1` → yardım buffer’ı
- Çıkış: `:q` / `:q!` → ana buffer’a dönüş

### Alternatifler
| Editör | Not |
|---|---|
| **Nano** | Basit, öğrenmesi kolay |
| **Micro** | Daha da hafif |
| **Emacs** | Çok güçlü; çoğu sistemde varsayılan kurulu değil |
| **Neovim** | Vim’in modern çatalı |

Hangi makineye gidersen git çoğu zaman karşında yine **Vim** vardır.

### `EDITOR` ortam değişkeni
Git commit, bazı araçlar vb. varsayılan editörü buradan alır:

```bash
echo $EDITOR
export EDITOR=vim
```

Kalıcılık için `.bashrc` / benzeri startup dosyasına eklenebilir.

### Pratik
```bash
vimtutor        # etkileşimli Vim eğitimi (geçici kopya, dosya bozma riski yok)
vimtutor tr     # Türkçe
```
