# LPIC-105.2 — Linux Commands Used in This Lesson

## Komutlar ve sözdizimi

| Komut / sözdizimi | Anlamı |
|---|---|
| `komut1 ; komut2` | Sırayla çalıştırır; ilki başarısız olsa da ikincisi çalışır |
| `komut1 && komut2` | İlki başarılıysa (exit 0) ikincisini çalıştırır |
| `komut1 \|\| komut2` | İlki başarısızsa ikincisini çalıştırır |
| `komut &` | Komutu arka planda çalıştırır |
| `echo $?` | Önceki komutun exit status değerini gösterir |
| `#!/bin/bash` | Shebang — script’i Bash ile çalıştır |
| `chmod +x script.sh` | Script’e çalıştırma izni verir |
| `./script.sh` | Geçerli dizindeki script’i çalıştırır |
| `bash script.sh` / `sh script.sh` | Interpreter ile çalıştırır |
| `$(komut)` | Command substitution |
| `` `komut` `` | Eski backtick biçimi (`$(…)` tercih edilir) |
| `exec komut` | Mevcut shell process’ini komutla değiştirir |
| `test koşul` / `[ koşul ]` | Koşul kontrolü; exit status döner |
| `if …; then …; else …; fi` | Koşullu blok |
| `exit 0` / `exit 1` | Başarılı / hatalı çıkış |
| `read değişken` | Kullanıcıdan girdi alır |
| `for x in liste; do …; done` | Liste üzerinde döngü |
| `while [ koşul ]; do …; done` | Koşul true iken döngü |
| `seq 1 5` | 1’den 5’e sıralı sayılar üretir |
| `{1..5}` | Brace expansion ile sayı aralığı |
| `let sayac+=1` | Aritmetik (`$` kullanılmaz) |

## Seçenekler ve özel değişkenler (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| script parametreleri | `$0` / `$1` / `$2` / `$#` | Script adı / 1.–2. parametre / sayı |
| `test` / `[` | `-e` / `-f` / `-d` | Var mı / normal dosya / dizin |
| `test` / `[` | `-r` / `-w` / `-x` / `-s` / `-L` | Okuma / yazma / execute / boyut>0 / symlink |
| `test` / `[` | `=` / `!=` / `-z` / `-n` | String eşit / değil / boş / boş değil |
| `test` / `[` | `-eq` / `-ne` / `-lt` / `-le` / `-gt` / `-ge` | Sayısal karşılaştırma |
| `read` | `-p "…"` | Prompt ile girdi |
| `read` | `-t N` | N saniye timeout |
| `chmod` | `+x` / `755` | Çalıştırma izni |
