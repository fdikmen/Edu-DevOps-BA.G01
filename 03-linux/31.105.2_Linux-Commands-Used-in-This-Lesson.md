# LPIC-105.2 — Linux Commands Used in This Lesson

| Komut / Sözdizimi | Anlamı |
|---|---|
| `komut1 ; komut2` | Sırayla çalıştırır; ilki başarısız olsa da ikincisi çalışır |
| `komut1 && komut2` | İlki başarılıysa (exit 0) ikincisini çalıştırır |
| `komut1 \|\| komut2` | İlki başarısızsa ikincisini çalıştırır |
| `komut &` | Komutu arka planda çalıştırır (`&&` değil) |
| `echo $?` | Önceki komutun exit status değerini gösterir |
| `#!/bin/bash` | Shebang — script'i Bash interpreter ile çalıştır |
| `chmod +x script.sh` | Script'e çalıştırma izni verir |
| `chmod 755 script.sh` | rwxr-xr-x ile çalıştırılabilir yapar |
| `./script.sh` | Geçerli dizindeki script'i çalıştırır |
| `bash script.sh` | Shebang gerekmeden Bash ile çalıştırır |
| `sh script.sh` | sh uyumluluk yorumlayıcısı ile çalıştırır |
| `$0` | Script'in adı |
| `$1` / `$2` | 1. / 2. parametre |
| `$#` | Toplam parametre sayısı |
| `"$1"` | Parametreyi tırnak içinde güvenli kullanır |
| `$(komut)` | Command substitution — komut çıktısını yerleştirir |
| `` `komut` `` | Eski backtick biçimi (`$(…)` tercih edilir) |
| `date +%Y-%m-%d` | YYYY-MM-DD formatında tarih üretir |
| `exec komut` | Mevcut shell process'ini komutla değiştirir |
| `test -e yol` | Yol var mı kontrol eder |
| `test -d dizin` | Dizin mi kontrol eder |
| `[ koşul ]` | `test` ile aynı (köşeli parantez sözdizimi) |
| `touch dosya` | Boş dosya oluşturur / zaman damgası günceller |
| `mkdir dizin` | Dizin oluşturur |
| `ls -ltr \| tail -3` | Zamana göre liste; son 3 satır |
