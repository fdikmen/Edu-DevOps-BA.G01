# LPIC-104.6 & 104.7 — Hard/Soft Link, FHS ve Dosya Bulma

## Konu
İki konu birlikte: **104.6** hard/soft link (`ln`) · **104.7** FHS (File System Hierarchy Standard) ve dosya bulma (`PATH`, `which`, `locate`…).

---

## inode ve Link Kavramı
**inode** — dosyanın metadata'sı ve disk konumu; isimden bağımsız.

| Tür | Nasıl çalışır? |
|---|---|
| **Hard link** | Aynı inode'a ikinci bir isim (`ln a b`) |
| **Soft link (symlink)** | Hedef yolu gösteren ayrı dosya (`ln -s a c`) |

Windows kısayoluna benzer ama mantık farklı:
- **b** (hard) ↔ **a** aynı veri; `a` silinse **b** çalışır
- **c** (soft) ↔ **a** yoluna işaret; `a` silinince **c** bozuk (dangling/broken) olur

```bash
mkdir links && cd links
touch a
ln a b              # hard link
ln -s a c           # soft link
ls -li              # inode + detay; c satırında -> a
echo "Hello World" > a
ls -li              # a ve b aynı boyut; c kendi boyutu (yol uzunluğu)
rm a                # b çalışır; cat c → No such file
```

| | Hard link | Soft link |
|---|---|---|
| inode | a ile **aynı** | **farklı** |
| `a` silinince | b çalışır | c bozulur |
| Farklı dosya sistemi | ❌ | ✅ |
| Dizin | normal kullanıcı ❌ | ✅ (`ln -s`) |
| Silme | `rm` / `unlink` | `rm` |

```bash
ls -i               # sadece inode numaraları
mkdir folderA
ln folderA hardlinkB    # hata: hard link not allowed for directory
ln -s folderA softlinkC # OK
find . -type l          # sembolik linkleri bul
find /usr/bin -type l   # sistemdeki symlink'ler
```

### Gerçek kullanım: sürüm zinciri
```bash
ln -s /usr/bin/python3.12 /usr/bin/python3
ln -s /usr/bin/python3 /usr/bin/python
# python → python3 → python3.12 → gerçek binary
which python3
ls -l /usr/bin/python3
```
Java, kütüphaneler (`lib_blah3` → `lib_blah_3.123`) için de aynı mantık.

## FHS — Kök Dizin Yapısı
`ls /` — standart hiyerarşi; dağıtımlar arası tutarlılık.

| Dizin | Görev |
|---|---|
| `/bin` | Temel komut ikilileri (`grep`, `rm`, `cat`…) |
| `/boot` | Bootloader statik dosyaları |
| `/dev` | Cihaz dosyaları |
| `/etc` | Sistem / uygulama **yapılandırma** dosyaları |
| `/lib` | Temel paylaşılan kütüphaneler, kernel modülleri |
| `/media` | Çıkarılabilir ortam mount noktası (USB vb.) |
| `/mnt` | Geçici, elle mount |
| `/opt` | Ek / üçüncü parti uygulama paketleri |
| `/sbin` | Temel **sistem** ikilileri (`fsck`, LVM araçları…) |
| `/srv` | Service verileri (FTP, web site dosyaları…) |
| `/tmp` | Geçici dosyalar |
| `/usr` | İkincil hiyerarşi (`/usr/bin`, `/usr/lib` — statik, çoğu yazılamaz) |
| `/var` | Yazılabilir veri: **loglar** (`/var/log`), cache, DB, mail, spool |
| `/home` | Kullanıcı home dizinleri |
| `/root` | root kullanıcısının home'u (`/home` dışında) |

Yapılandırma arıyorsan → `/etc`. Log arıyorsan → `/var/log`.

## PATH ile Komut Bulma
```bash
echo $PATH          # : ile ayrılmış dizin listesi
export PATH=$PATH:/home/tommy/w
```
Shell komutu soldan sağa PATH dizinlerinde arar; bulamazsa `command not found`.

| Komut | Ne yapar |
|---|---|
| `which ping` | PATH'te **ilk** bulunan çalıştırılabilir dosya |
| `which -a ping` | PATH'teki tüm eşleşmeler |
| `whereis ping` | binary + man + kaynak konumları |
| `whatis ping` | Man'den kısa açıklama |
| `type cd` | `cd is a shell builtin` |
| `type ping` | `ping is /usr/bin/ping` |

`cd` gibi komutlar **builtin** — `which` sonuç vermez; `type` kullan.

## find — Kullanıcı / Grup Filtreleri
Önceki derste `-name`, `-size`, `-mtime`… Bu derste ek seçenekler:

```bash
find /home -user tommy
find /home -not -user tommy
find /home -nouser
find /home -group developers
find /home --max-depth 1 -user tommy   # sadece bir seviye derinlik
```

## locate & updatedb — Hızlı Arama
`find /` tüm ağacı tarar → yavaş; izin hataları (`Permission denied`) için `sudo` gerekebilir.

```bash
sudo find / -iname "*VMware*"
sudo updatedb              # veritabanını güncelle
locate VMware
locate networking
```

- `locate` önceden oluşturulmuş DB kullanır → çok hızlı
- DB canlı değil; yeni dosya hemen görünmeyebilir
- `updatedb` genelde **cron** ile günlük çalışır
- Debian'da bazen `plocate` paketi; yapılandırma `/etc` altında (prune paths = tarama dışı dizinler)

---

## Özet
- **Hard link** = aynı inode; **soft link** = yol referansı
- `ln` / `ln -s`; dizin ve farklı FS → soft link
- FHS: `/etc` config, `/var/log` log, `/usr` programlar, `/bin` temel komutlar
- `PATH`, `which`, `whereis`, `whatis`, `type`
- `find -user/-group/--max-depth`; `locate` + `updatedb`

**Not:** LPIC-1 101 sınav konularının son bölümü; sırada 102 sınav konuları.
