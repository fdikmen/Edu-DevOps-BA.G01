# LPIC-108.4 — Linux Commands Used in This Lesson

| Komut / Yol / Sözdizimi | Anlamı |
|---|---|
| CUPS | Common Unix Printing System; yazdırmayı uçtan uca yönetir |
| LPD | Line Printer Daemon; eski yazdırma arayüzü ailesi |
| BSD | Berkeley Software Distribution; klasik `lpr`/`lpq`/`lprm`/`lpc` kökeni |
| `sudo apt install cups` | CUPS paketini kurar (Debian/Ubuntu) |
| `/usr/sbin/cupsd` | CUPS daemon ana süreç |
| `systemctl status cups` | CUPS servis durumu |
| `journalctl -u cups` | CUPS birim günlükleri |
| spool | İşlerin yazıcıya gitmeden beklediği alan |
| Port **631** | CUPS web arayüzü |
| `http://localhost:631` | Yerel CUPS web UI |
| `/etc/cups` | CUPS yapılandırma dizini |
| `cupsd.conf` | Daemon ve erişim ayarları |
| `MaxLogSize 0` | Log rotasyonunu kapatır |
| `Listen localhost:631` | Yalnızca yerel dinleme |
| `Listen 0.0.0.0:631` | Tüm arayüzlerde dinleme (ağ erişimi) |
| `/admin` · `/admin/conf` | Yönetim yolları; sistem yetkisi ister |
| `printer-admins` | Örnek yönetim grubu adı |
| `CUPS-Add-Modify-Printer` | Yazıcı ekleme/değiştirme işlem sınırı |
| `CUPS-Delete-Printer` | Yazıcı silme işlem sınırı |
| `/etc/cups/printers.conf` | Tanımlı yazıcı kayıtları |
| PPD | PostScript Printer Description; model yetenekleri |
| PostScript | Sayfa tanımlama dili |
| UUID | Universally Unique Identifier; yazıcı kimliği |
| URL | Uniform Resource Locator; yazıcı bağlantı adresi |
| PCL | Printer Command Language |
| `ls /var/log/cups/` | CUPS access/error log dizinini listeler |
| `/var/log/cups/` | CUPS günlük dizini |
| access log / error log | Erişim ve hata günlükleri |
| `lpinfo -m` | Kurulu / bilinen yazıcı modellerini (PPD) listeler |
| `lpinfo -m \| grep -i "hp"` | HP ile ilgili modelleri süzer |
| `lpinfo -m \| head` | Model listesinin başını gösterir |
| `sudo lpadmin -p my_printer -v socket://192.168.1.100 -E -m "…ppd…"` | Yazıcı ekler: ad, URI, etkin, model |
| `-p` | Yazıcı adı |
| `-v` | Bağlantı URI’si |
| `-E` | Yazıcıyı etkinleştirir |
| `-m` | Model / PPD |
| `sudo lpadmin -d my_printer` | Varsayılan yazıcıyı ayarlar |
| `lpstat -p my_printer` | Yazıcı durumunu gösterir |
| `lpstat -d` | Varsayılan yazıcıyı gösterir |
| `lpstat -o` | Bekleyen işleri listeler |
| `sudo cupsaccept my_printer` | Yazıcının yeni işleri kabul etmesini sağlar |
| `sudo cupsenable my_printer` | Yazdırmayı (cihaza göndermeyi) açar |
| `echo "CUPS test print" > test.txt` | Test dosyası oluşturur |
| `lp -d my_printer test.txt` | Dosyayı adlandırılmış yazıcıya gönderir |
| `lp -d "my printer" test.txt` | Boşluklu yazıcı adıyla gönderim |
| `cups-bsd` | CUPS’ın BSD legacy komut uyumluluk paketi |
| `lpr` | line printer — iş gönderir |
| `lpq` | line printer queue — kuyruğu listeler |
| `lprm` | line printer remove — iş siler |
| `lpc` | line printer control — yazıcı durumunu denetler |
| `echo "CUPS legacy tools test" > myfile` | Legacy deneme dosyası |
| `cat myfile` | Dosya içeriğini gösterir |
| `lpr myfile` | Varsayılan yazıcıya gönderir; yoksa hata verebilir |
| `no default destination` | Varsayılan yazıcı tanımlı değil |
| `lpr -P "my printer" myfile` | Adlandırılmış yazıcıya gönderir |
| `-P` | Yazıcı / kuyruk adı |
| `lpq -P "my printer"` | Belirli yazıcının kuyruğu |
| `lpq -a` | Tüm kuyruklar |
| `lprm -P "my printer" 8` | 8 numaralı işi siler |
| `lprm -P "my printer" -` | Yazıcıdaki tüm işleri silmeyi dener |
| `forbidden` | Yetki yok (ör. tüm işleri silmek) |
| `sudo lprm -P "my printer" -` | Root ile tüm işleri siler |
| `sudo lpc status` | Queuing / printing durumunu gösterir |
| queuing is enabled | Kuyruğa yeni iş kabul açık |
| printing is enabled | Cihaza gönderme açık |
| `cupsreject "my printer"` | Yeni işleri reddeder |
| `cupsaccept "my printer"` | Yeni işleri kabul eder |
| `cupsdisable "my printer" -r "needs more paper"` | Yazdırmayı kapatır; neden mesajı ekler |
| `-r` | Durum / neden metni |
| `cupsenable "my printer"` | Yazdırmayı yeniden açar |
| Braille | Kabartma yazı sistemi; örnek sanal/özel yazıcı |
