# LPIC-108.4 — Linux Commands Used in This Lesson

## Komutlar ve yollar

| Komut / yol | Anlamı |
|---|---|
| `sudo apt install cups` | CUPS paketini kurar (Debian/Ubuntu) |
| `systemctl status cups` | CUPS servis durumu |
| `journalctl -u cups` | CUPS birim günlükleri |
| `/usr/sbin/cupsd` | CUPS daemon ana süreç |
| `/etc/cups/` | CUPS yapılandırma dizini |
| `/etc/cups/cupsd.conf` | Daemon, dinleme ve erişim ayarları |
| `/etc/cups/printers.conf` | Tanımlı yazıcı kayıtları |
| `/var/log/cups/` | CUPS günlük dizini (access / error) |
| `ls /var/log/cups/` | CUPS log dosyalarını listeler |
| `http://localhost:631` | Yerel CUPS web arayüzü (port 631) |
| `lpinfo -m` | Bilinen yazıcı modellerini / PPD listesini gösterir |
| `sudo lpadmin -p … -v … -E -m …` | Yazıcı ekler (ad, URI, etkin, model) |
| `sudo lpadmin -d yazıcı` | Varsayılan yazıcıyı ayarlar |
| `lpstat -p yazıcı` | Yazıcı durumunu gösterir |
| `lpstat -d` | Varsayılan yazıcıyı gösterir |
| `lpstat -o` | Bekleyen işleri listeler |
| `lp -d yazıcı dosya` | Dosyayı adlandırılmış yazıcıya gönderir |
| `cups-bsd` | CUPS’ın BSD legacy uyumluluk paketi |
| `lpr` | Legacy: yazdırma işi gönderir |
| `lpq` | Legacy: kuyruğu listeler |
| `lprm` | Legacy: kuyruktan iş siler |
| `lpc` | Legacy: yazıcı durumunu / denetimini gösterir |
| `sudo lpc status` | Queuing ve printing durumunu gösterir |
| `cupsaccept yazıcı` | Yeni işleri kuyruğa kabul eder |
| `cupsreject yazıcı` | Yeni işleri reddeder |
| `cupsenable yazıcı` | Cihaza göndermeyi (yazdırmayı) açar |
| `cupsdisable yazıcı` | Cihaza göndermeyi kapatır |
| `lpr -P "yazıcı" dosya` | Adlandırılmış yazıcıya iş gönderir |
| `lpq -P "yazıcı"` | Belirli yazıcının kuyruğu |
| `lpq -a` | Tüm kuyruklar |
| `lprm -P "yazıcı" işno` | Belirli işi siler |
| `sudo lprm -P "yazıcı" -` | Yazıcıdaki tüm işleri siler (root) |

## Seçenekler, menü ve çıktı (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| `lpadmin` | `-p` | Yazıcı adı |
| `lpadmin` | `-v` | Bağlantı URI’si |
| `lpadmin` | `-E` | Yazıcıyı etkinleştirir |
| `lpadmin` | `-m` | Model / PPD |
| `lpadmin` | `-d` | Varsayılan yazıcı yap |
| `lpr` / `lpq` / `lprm` | `-P` | Yazıcı / kuyruk adı |
| `lpq` | `-a` | Tüm kuyrukları göster |
| `lprm` | `-` (iş yerine) | Tüm işleri silmeyi dene |
| `cupsdisable` | `-r "metin"` | Durdurma nedeni mesajı |
| `cupsd.conf` | `Listen localhost:631` | Yalnızca yerel dinleme |
| `cupsd.conf` | `Listen 0.0.0.0:631` | Tüm arayüzlerde dinleme |
| `cupsd.conf` | `MaxLogSize 0` | Log rotasyonunu kapatır |
| `cupsd.conf` | `/admin`, `/admin/conf` | Yönetim yolları (yetki ister) |
| CUPS web UI | **Home** | Genel görünüm |
| CUPS web UI | **Administration** | Sunucu / yazıcı yönetimi, Add Printer |
| CUPS web UI | **Jobs** | Kuyruktaki işler |
| CUPS web UI | **Printers** | Yazıcı listesi |
| CUPS web UI | **Maintenance** | Test, duraklat, reddet, taşı, iptal |
| `lpr` çıktısı | `no default destination` | Varsayılan yazıcı yok |
| `lprm` çıktısı | `forbidden` | Yetki yetersiz |
| `lpc status` çıktısı | `queuing is enabled` | Kuyruğa kabul açık |
| `lpc status` çıktısı | `printing is enabled` | Cihaza gönderme açık |
