# LPIC-103.8 — Linux Commands Used in This Lesson

## Komutlar (shell)

| Komut | Anlamı |
|---|---|
| `vi` / `vim` | VI / Vim editörünü açar |
| `which vi` / `which vim` | Binary konumunu gösterir |
| `vimtutor` / `vimtutor tr` | Etkileşimli Vim eğitimi |
| `echo $EDITOR` | Varsayılan editör değişkenini gösterir |
| `export EDITOR=vim` | Varsayılan editörü Vim yapar |

## Vim tuşları ve ex komutları (shell komutu değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| insert | `i` / `I` / `a` | Insert / satır başı / append |
| normal | `Esc` | Insert → normal mode |
| hareket | `h` `j` `k` `l` | Sol / aşağı / yukarı / sağ |
| hareket | `w` / `b` / `e` | Kelime ileri / geri / son |
| hareket | `Ctrl+F` / `Ctrl+B` | Sayfa aşağı / yukarı |
| hareket | `G` / `gg` / `NG` | Dosya sonu / başı / N. satır |
| hareket | `H` / `L` | Ekranın üstü / altı |
| düzenleme | `r` / `o` / `O` | Replace / alt-üst yeni satır |
| silme | `x` / `X` / `dw` / `dd` | Karakter / kelime / satır sil |
| yank/paste | `y` / `yy` / `p` / `P` / `xp` | Kopyala / yapıştır / yer değiştir |
| arama | `/metin` / `?metin` / `n` / `N` | İleri / geri ara / sonraki / önceki |
| ex | `:q` / `:q!` / `:w` / `:w!` / `:wq` / `ZZ` | Çık / kaydet / yaz-çık |
| ex | `:e!` / `:help` / `F1` | Yeniden oku / yardım |
| ex | `:! komut` | Vim içinden shell komutu |
