# LPIC-103.8 — Linux Commands Used in This Lesson

| Komut / Sözdizimi | Anlamı |
|---|---|
| `vi` / `vim` | VI / Vim editörünü açar (çoğu sistemde `vi` → Vim) |
| `which vi` / `which vim` | Binary konumunu gösterir |
| `vimtutor` / `vimtutor tr` | Etkileşimli Vim eğitimi (Türkçe: `tr`) |
| `i` / `I` | Insert mode (imleç öncesi / satır başı) |
| `a` | Append — imlecin sağına insert |
| `Esc` | Insert → normal mode |
| `h` `j` `k` `l` | Sol / aşağı / yukarı / sağ |
| `w` / `b` / `e` | Kelime başı ileri / geri / kelime sonu |
| `Ctrl+F` / `Ctrl+B` | Sayfa aşağı / yukarı |
| `G` / `gg` / `NG` | Dosya sonu / başı / N. satır |
| `H` / `L` | Ekranın üstü / altı |
| `r` | Tek karakter replace |
| `o` / `O` | Altında / üstünde yeni satır + insert |
| `x` / `X` / `Nx` | Karakter sil (üzeri / sol / N adet) |
| `dw` / `Ndw` / `dd` / `Ndd` | Kelime / satır silme |
| `y` / `yy` | Yank (kopyala) / satır kopyala |
| `p` / `P` | Sonrasına / öncesine yapıştır |
| `xp` | İki karakteri yer değiştir |
| `/metin` / `?metin` | İleri / geri ara |
| `n` / `N` | Sonraki / önceki eşleşme |
| `:q` / `:q!` | Çık / kaydetmeden zorla çık |
| `:w` / `:w!` / `:wq` | Kaydet / zorla yaz / yaz ve çık |
| `ZZ` | Yaz ve çık |
| `:e!` | Diskteki orijinal hâli yeniden oku |
| `:help` / `F1` | Yardım buffer’ı |
| `:! komut` | Vim içinden shell komutu (örn. `:! ls`) |
| `echo $EDITOR` | Varsayılan editör değişkenini göster |
| `export EDITOR=vim` | Varsayılan editörü Vim yap |
