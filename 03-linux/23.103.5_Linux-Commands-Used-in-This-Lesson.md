# LPIC-103.5 — Linux Commands Used in This Lesson

| Komut / Sözdizimi | Anlamı |
|---|---|
| `kill -l` | Sistemdeki sinyalleri listeler |
| `kill -1` / `-2` / `-9` / `-15` / `-18` / `-19` | HUP / INT / KILL / TERM / CONT / STOP |
| `sleep N &` | N saniye bekleyen arka plan process'i (deneme için) |
| `jobs` | Mevcut shell işlerini listeler |
| `ps` | Bu shell oturumundaki process'leri gösterir |
| `ps -e` | Sistemdeki tüm process'leri listeler |
| `ps -ef` | Tüm process'leri detaylı gösterir (UID, PID, PPID, CMD…) |
| `ps aux` | Tüm kullanıcı process'leri + %CPU / %MEM |
| `ps -ef \| grep isim` | İsme göre process satırı bulur |
| `pgrep isim` | İsme göre yalnızca PID basar |
| `pgrep … \| xargs kill` | Bulunan PID'lere toplu kill |
| `top` | Canlı process / CPU / bellek izleme |
| `Shift+M` (top içinde) | Memory kullanımına göre sıralar |
| `c` / `k` / `q` (top) | Tam komut / kill / çıkış |
| `free` / `free -h` / `free -g` | Bellek durumu (ham / okunabilir / GB) |
| `uptime` / `uptime -p` | Çalışma süresi + load average / pretty |
| `watch komut` | Komutu periyodik yeniler (~2 sn) |
| `watch -n N` | Yenileme aralığını N saniye yapar |
| `watch -b` / `-d` | Hata bip / değişenleri vurgula |
| `df -h` | Disk kullanımını okunabilir gösterir |
| `screen` | Terminal multiplexer oturumu başlatır |
| `screen -ls` | screen oturumlarını listeler |
| `screen -r N` | Oturuma yeniden bağlanır (reattach) |
| `Ctrl+A d` | screen'den detach |
| `Ctrl+A c/n/p/k` | Yeni / sonraki / önceki pencere / kapat |
| `tmux` | Modern terminal multiplexer |
| `tmux ls` | tmux oturumlarını listeler |
| `tmux attach -t N` | Oturuma yeniden bağlanır |
| `Ctrl+B d` | tmux'tan detach |
| `Ctrl+B %` / `"` | Dikey / yatay bölme |
| `Ctrl+B c` | Yeni tmux penceresi |
| `wc -l` | Satır sayısı (`ps -e \| wc -l`) |
| `head` / `tail` | Çıktının başı / sonu |
