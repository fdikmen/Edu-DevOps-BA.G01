# LPIC-103.5 — Linux Commands Used in This Lesson

## Komutlar

| Komut | Anlamı |
|---|---|
| `kill` | Process’e sinyal gönderir |
| `kill -l` | Sistemdeki sinyalleri listeler |
| `jobs` | Mevcut shell işlerini listeler |
| `ps` | Bu shell oturumundaki process’ler |
| `ps -e` / `ps -ef` / `ps aux` | Sistem / detaylı / BSD stili tüm process’ler |
| `pgrep isim` | İsme göre PID basar |
| `pgrep … \| xargs kill` | Bulunan PID’lere toplu kill |
| `top` | Canlı process / CPU / bellek izleme |
| `free` / `free -h` / `free -g` | Bellek durumu |
| `uptime` / `uptime -p` | Çalışma süresi + load average |
| `watch komut` | Komutu periyodik yeniler |
| `screen` | Terminal multiplexer oturumu |
| `screen -ls` / `screen -r N` | Listele / reattach |
| `tmux` | Modern terminal multiplexer |
| `tmux ls` / `tmux attach -t N` | Listele / reattach |

## Seçenekler, tuşlar ve sinyaller (bağımsız komut değildir)

| Bağlam | Öğe | Anlamı |
|---|---|---|
| `kill` | `-1` / `-2` / `-9` / `-15` / `-18` / `-19` | HUP / INT / KILL / TERM / CONT / STOP |
| `watch` | `-n N` / `-b` / `-d` | Aralık / hata bip / fark vurgusu |
| `top` içinde | `Shift+M` / `c` / `k` / `q` | Belleğe göre sırala / tam komut / kill / çık |
| `screen` | `Ctrl+A d` | Detach |
| `screen` | `Ctrl+A c/n/p/k` | Yeni / sonraki / önceki / kapat |
| `tmux` | `Ctrl+B d` | Detach |
| `tmux` | `Ctrl+B %` / `"` / `c` | Dikey / yatay böl / yeni pencere |
